# 따로 같이 네컷 - 디자인 리뷰 R3 (2026-10-27)

관점: 10~20대 앱 디자이너. 자료: packet3 (landing 모션 시트, fixed-/movable- 화면, outline-booth-purple).
한 줄: 새 기능(합체 모션, 둥둥 A, 테두리 탭)의 아이디어는 맞다. 하지만 R1의 "촬영 화면 빈 면적"이 그대로 남았고,
움직이기 기능은 **쓸 수 있다는 신호가 화면에 없다.**

## MUST (3)

### 1. [MUST] 촬영 화면 - 분홍 점무늬 패널 + 4:3 회색 띠 + 셔터 아래 빈칸 (R1 #1 미해결)
- 문제: 2x 기준 카메라 영역은 y 470~1065(약 600px)뿐이고, 위 315px·아래 280px는 점무늬 분홍,
  셔터 아래 190px는 빈 크림이다. 그 사이 회색(#dcd5cf)·청회색 띠가 "로딩 안 된 칸"처럼 보인다.
  B 라이브 영상은 직사각형 hard edge(x392)로 끊겨 A 컷아웃 옆에 "붙인 사진"처럼 보이고,
  점선 가이드(y1020)가 영상 하단(y1065)보다 위라서 가이드와 실제 프레임이 안 맞는다.
- 수정:
  - `.stage{ background:var(--paper); aspect-ratio:auto; flex:1; min-height:56svh; }` 분홍 점무늬 패널 제거.
    촬영 영역 = 결과 칸 비율 box 하나. 영상은 `object-fit:cover; inset:0`으로 그 box를 꽉 채운다.
  - 가이드 점선은 box 바깥 테두리가 아니라 box의 `inset:6px`, 영상과 같은 `border-radius:20px`로 clip.
  - 판 위 하단 "셔터 한 번이면…" pill은 유지하되 `bottom:12px`, 첫 컷 후 사라지게.
  - 셔터 아래는 `padding-bottom: max(24px, env(safe-area-inset-bottom))`로 빈칸 대신 safe area만.

### 2. [MUST] 움직이기/크기 조절 어포던스가 없다
- 화면: movable-08-b-shoot-ready / dragged / pinched
- 문제: B 화면에 A를 "잡을 수 있다"는 단서가 0이다. 오른쪽 위 어두운 "원래 자리" pill 하나뿐이고(높이 약 31px,
  탭 타깃 44px 미만), 항상 떠 있어서 아직 안 움직였는데도 눌러야 할 것처럼 보인다.
  pinch 화면도 A 가장자리에 아무 표시가 없다.
- 수정:
  - A 컷아웃 둘레에 `outline:2px dashed #fff; filter:drop-shadow(0 0 0 #fff8)` 대신 흰 점선 박스 + 네 모서리 8px
    흰 점(핸들). 드래그 중에는 핸들 `#ff7eb6` 로 바뀐다. 첫 진입 2.5초만 이 박스가 `pulse`(opacity .5→1).
  - 코치 pill (1회, 탭하면 사라짐): `A를 끌어서 옮기고, 두 손가락으로 키워 봐 ✋`.
  - "원래 자리"는 **움직인 뒤에만** 나타나게: `opacity:0 → 1`, 아이콘 ↺ + 라벨, `min-height:44px; padding:0 16px;
    background:var(--paper); color:var(--deep); box-shadow:0 2px 8px #0002`. 어두운 pill은 안내 pill과 같은 색이라 헷갈린다.
  - A 컷아웃은 box 안으로만 클램프(바깥으로 못 나가게)하고, 놓을 때 `transition:transform .18s cubic-bezier(.3,1.5,.5,1)`.

### 3. [MUST] 토글 카피가 같은 말을 두 번 한다 + 리뷰 화면이 검은 상자
- 화면: movable-02-a-toggle-on (4/4 리뷰)
- 문제: 제목 "친구가 나를 옮기고 크기 바꿀 수 있게" / 부제 "친구가 끌어서 옮기고 크기를 바꿀 수 있어" - 거의 동일.
  제목은 길어서 토글과 한 줄에 못 들어가고(Jua 17px 굵게), 끄면 어떻게 되는지 안 알려 준다.
  리뷰 stage는 #2e2230 거대 블록 안에 회색 2x2 칸이라 귀여움이 사라지고, 회색 칸은 R3 이전의 "빈 칸" 문제 재발이다.
- 수정:
  - 제목 `친구가 내 위치를 바꿀 수 있게` (14자), 부제 `켜면 친구가 날 끌어서 옮기고 키울 수 있어. 끄면 이 자리 그대로`.
    토글 행 `padding:14px 16px; gap:12px`, 제목 `font-size:16px`, 부제 `13px; color:#7a6a78`.
  - 리뷰 stage 배경을 `var(--paper)` + 컷 4장 2x2에 `gap:8px; border-radius:14px`, 칸 배경은 회색 대신 booth-pink.
    썸네일 "다시" 라벨과 번호가 겹치므로 번호 삭제(라벨만).
  - 안내문 "다시 찍고 싶은 컷은 눌러 줘"는 stage 아래 1줄 유지, 보관 안내(7일)는 이 화면에서 삭제(R1 #10 미해결).

## 그 외 (영향 순)

### 4. 테두리 탭 칩 - 선택 상태가 한꺼번에 3개 켜진 것처럼 보인다
- 문제: `없음`(선택) + `실선` + `보통`이 전부 같은 연분홍 채움이라, 테두리가 꺼져 있는데도 모양·굵기가 켜진 것처럼
  읽힌다(movable-10). 행 라벨이 없고, 칩 폭이 112/112/140으로 들쭉날쭉하며, 색 원 선택은 링 표시가 약하다.
- 수정:
  - 행 앞에 12px 라벨 `색` `모양` `굵기`. 칩은 3열 그리드 `display:grid; grid-template-columns:repeat(3,1fr); gap:8px;
    height:44px` 로 폭을 맞춘다.
  - `없음` 선택 시 나머지 두 행 `opacity:.35; pointer-events:none`. 선택 칩은 `background:#fff;
    border:2px solid var(--pink); color:var(--deep)`, 비선택은 `background:#fff; border:1px solid #f0dde6`.
  - 색 원 선택 = `box-shadow:0 0 0 3px #fff, 0 0 0 5px var(--pink)`.
  - 기본값은 `solid · white · normal`(스티커 느낌이 가장 Gen-Z). 모양 `반짝이`와 `점선`은 유지.

### 5. 스티커 테두리 품질 (outline-booth-purple)
- 보라 배경에서 흰 solid/pink solid는 깔끔하다. 문제는 (a) 컷아웃 경계의 옅은 청록 fringe(A 어깨), (b) black glitter가
  지저분해 보임, (c) dotted thick 점이 너무 굵어 어깨 부분에서 끊김(점이 하단에서 잘림), (d) 두 사람이 붙으면 테두리가
  하나로 합쳐져 한 덩어리 스티커로 보임(좋다 - 이건 유지).
- 수정: 테두리 생성 전 마스크를 1px 침식 + fringe 제거, `glitter × black` 조합 삭제(또는 `glitter`는 white·pink만),
  dotted `thick`은 점 지름 상한 12px로 줄이고 이미지 가장자리 안쪽으로 clip 하지 않기(`overflow:visible` 후 padding 여유).

### 6. 완성 화면 밀도 - CTA 4개가 한 시트에
- 문제: `저장하기`(채움) + 진행 버튼(`프레임 끼우는 중 1%`, `리본 묶는 중 0%` - 탭마다 문구가 달라 귀엽지만 회색 비활성
  버튼처럼 보임) + `스토리용 영상` + `다른 친구랑도 찍기` + 링크 2개. `짠, 완성!`은 스트립 하단에 붙어 있고(y 815 vs 스트립 끝 790)
  그 아래 구분선도 겹쳐 잘려 보인다.
- 수정:
  - 하단 `position:sticky; bottom:0` 바에 `저장하기`(flex:1)와 `영상` 보조 버튼(56px 정사각 아이콘) 두 개만.
  - 진행 중에는 버튼 자체를 채움 바로(`linear-gradient(90deg,var(--pink) X%,var(--pink-soft) X%)`, 라벨 `리본 묶는 중 43%`).
  - `다른 친구랑도 찍기`·`시켜본 것 더 보기`·삭제는 스크롤 끝 `fine` 텍스트 링크 한 줄로 내린다.
  - `짠, 완성!`은 스트립 위 `margin-bottom:12px`, 스트립과 시트 사이 `gap:16px`; 탭 바 `height:48px` 유지.

### 7. 랜딩 "착! 합체" 모션 - 방향은 맞지만 시간 배분이 늘어진다
- 시트(0.5초 간격) 판독: 0.3s 화면 전체가 비어 있음 → 0.9s 헤드라인은 이미 있고 반쪽 두 장이 **작게(스트립의 약 40%)** 맞닿아
  있음 → 1.3s 스파클 → 1.9s 스트립 완성. 즉 "날아오는" 구간이 시트에 안 잡히고(0.5~0.9s 사이 끝난 듯), 합체 후 스트립이
  커지는 구간도 0.6초 사이에 일어나 읽을 틈이 없다. 완성 후에는 완전 정지.
- 수정(값 제안, 실측 아님 - 시트로는 이징을 알 수 없다):
  - 0s에 헤더·헤드라인·CTA를 바로 보이게(0.3s 공백 제거). 모션은 히어로 영역만.
  - 0.1→0.65s: 반쪽 두 장이 좌우 `translateX(±60%) rotate(∓8deg)` → 0, `cubic-bezier(.34,1.56,.64,1)`(오버슈트).
  - 0.65s: 스파클 `scale(.6→1.1)` 180ms + 반쪽이 `scale(1.06→1)`.
  - 0.8→1.2s: 반쪽이 위아래로 이어지며 4컷 스트립으로 펼쳐짐(`clip-path` 또는 height 0→100%).
  - 끝: 스트립 `animation: bob 3.2s ease-in-out infinite` (±3px) + 별·하트 `twinkle`. `prefers-reduced-motion`이면 최종 상태만.
  - 전체 1.3초 이내. 지금은 완성까지 약 2초.
- 07 B 랜딩 시트: 스파클이 **A의 얼굴 위**에서 터진다(1.6s) - 얼굴 가리지 않게 우측 빈 영역(친구 자리)으로 옮겨 "여기로 온다"는
  방향성도 준다. 모션이 거의 없으므로 우측에 점선 아치 + 하트 `bob`을 두면 R1 #11도 해결.

### 8. B 랜딩 레이아웃 - 설명과 CTA 사이 약 15% 공백
- 문제: 히어로 이미지는 약 200px로 작고, 설명 아래 120px(2x 환산 약 240px)가 비어 CTA가 바닥에 붙는다. 하단 7일 안내 두 줄 +
  `내가 보낸 링크면 여기`까지 총 3줄이 CTA 아래에 쌓여 무겁다.
- 수정: 히어로 `aspect-ratio:4/5; width:100%; max-height:46svh`로 키우고, 카피를 히어로 아래 가까이. 안내는 한 줄
  `링크는 7일 뒤 사진과 함께 사라져요`. "친구 옆에 서면 돼" pill은 A 가슴 위가 아니라 우측 점선 아치 안으로.

### 9. 일관성 - 버튼·pill 색이 화면마다 다르다
- 어두운 pill(#4a3d4d 계열)이 안내·`원래 자리`·`다시` 라벨에 모두 쓰인다. 서로 다른 역할인데 같은 모양이다.
- 수정: 안내 = 어두운 반투명 pill, 액션 = 흰 pill + 아이콘, 상태 라벨(`다시`) = 핑크 soft. 그리고 `좌우반전`(분홍 채움) /
  `앞/뒤 카메라`(흰색)는 R1 #8 그대로 - 아직 색이 다르다. 둘 다 흰 56px + 11px 라벨, 켜진 것만 `--pink-soft`.

### 10. 귀여움 vs 깔끔함 - 전체 톤은 맞다, 장식은 한 곳만 더
- 팔레트·Jua는 유지. 지금 귀여움이 랜딩에만 몰려 있다. 촬영·완성 화면은 거의 UI만이라 차갑다.
- 수정: 촬영 중 셔터 위 카운트다운 숫자를 `Jua 120px; color:#fff; text-shadow:0 4px 0 var(--pink)`로, 완성 `짠, 완성!`에
  별 스파클 2개. 색 추가 금지.
