# Round 5 engine — 반려동물 누끼(움직이는 컷·라이브), 필터, 두 사람 빛 맞추기 (2026-10-28)

## 결론

1. **반려동물**: 사진에만 있던 DeepLab 개·고양이 합치기를 HQ 움직이는 컷과 라이브(촬영 미리보기) 컷에도 넣었다.
   사람만 있는 클립은 결과가 **완전히 같다**(평균 차 0). 움직이는 컷의 추가 시간은 클립 하나에 측정 잡음 수준
   (+0.4~2.5 s / 15~19 s). 라이브 미리보기 fps는 −2 %.
2. **필터**: 뽀샤시의 회색 베일을 걷어냈고(어두운 피부 luma 0.369 → 0.314, 원본 0.24, 채도 유지), 흑백은 진한 `흑백`과
   부드러운 `그레이` 두 개로 나눴다. 세기 3단계(약/중/강)는 필터 id 에 실어 보낸다(`"bbosasi:1"`).
3. **빛 맞추기**: 사람마다 한 번 계산한 채널별 gain 이 사진과 영상 프레임 모두에 같게 들어간다. 얼굴 밝기 차
   26 → 0.6, r/g 차 0.131 → 0.052, b/g 차 0.169 → 0.068.

## 1. 반려동물

| 경로 | 무엇을 | 비용 (PC headless) |
|---|---|---|
| HQ 사진 | 그대로 (MODNet ∪ DeepLab, `addPet`) | ~130 ms/장 |
| HQ 움직이는 컷 (`clipmatte.js`) | keyframe 마다 MODNet ∪ DeepLab. 동물이 있으면 매 keyframe, 없으면 3번째마다 확인 | ~77 ms/keyframe, 동물 없는 클립은 1/3 |
| 라이브 (`segmentFrame`) | `pet-worker.js` 에서 DeepLab 을 8프레임마다 1번 이하로 돌리고, 마지막 맵을 매 프레임 selfie 신뢰도에 max | fps 23.4 → 22.9 |

- DeepLab 을 페이지에서 클립 프레임에 돌리면 MediaPipe GPU 버퍼 풀이 깨졌다(`Failed to create buffer` → `Aborted()`,
  얼굴 랜드마크까지 죽고 꾸미기 화면이 멈춤, A→B walk 에서 2번 재현). 그래서 클립과 라이브는 worker 로 돈다(자기만의
  wasm). worker 가 3 s 안에 답이 없으면 그 회차는 "동물 없음", 3번 연속이면 페이지에서 끈다.
- 라이브 fps (`livebench.html`, 8 s씩 번갈아): 페이지에서 4프레임마다 23 → 18 fps(74 ms 끊김). worker 4프레임마다
  23.6 → 22.2(−6 %), **8프레임마다 23.4 → 22.9(−2 %)** ← 채택. p90 프레임 시간 18 → 40~50 ms.
- 사람만 있는 클립(walk a0, b0): 동물 켬/끔 rebuilt matte 차이 **0.000**, 시간 16.6 → 17.5 s, 15.5 → 16.0 s.
  개 클립(pet a0): 픽셀 10.3 % 가 바뀜(개 머리가 들어옴), 16.5 → 19.1 s.
