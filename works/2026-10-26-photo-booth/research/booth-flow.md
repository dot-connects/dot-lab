# 실제 부스 흐름 리서치 (2026-10-27)

**결론:** 부스 컷 수는 브랜드마다 다르다. 하루필름은 10컷 중 4컷 선택(공식 FAQ). 포토이즘·인생네컷은 6~10컷 후기가 섞여 있고 공식 수치는 못 찾았다. 컷당 타이머는 8~10초 후기가 다수. 포토이즘 공식 사이트(photoism.co.kr)는 WebFetch 403, 네이버 블로그/카페는 검색 도구가 접근 불가라 직접 못 읽었다. 이 때문에 포토이즘의 시각 정체성(색·서체·UI)과 8→4 선택 UI의 세부는 **확인 못 함**이다. 아래 [추정]은 추측이다.

## 1. 부스 흐름 (확인된 것만)

### 하루필름 (유일한 공식 1차 자료)
공식 FAQ의 화면 안내 8단계: 프레임 타입(Basic/ID) -> 컷 수(2/4/6/8/10) -> 인화 매수 -> 촬영("ten shots in total") -> 마음에 드는 컷 선택(고른 컷 수만큼) -> 프레임 디자인 -> 스티커 -> 인화. QR은 무료 서비스이며 10시간 안에 받지 않으면 삭제된다. https://harufilmusa.com/faq/
- 방콕 지점 후기: 약 10컷, "10 seconds per posture", 4컷이면 4장 선택 후 프레임 스타일 선택. 친구가 초를 세어 주면 좋다(화면을 보면 시선이 어긋남). https://www.lemon8-app.com/@piamrux/7243615736344723969?region=us

### 포토이즘 (후기 기반)
- 방콕 지점: 배경색(gray/white/blue/pink) 먼저 -> 줄 -> 결제 -> 프레임 선택 -> "timer for 10 seconds" -> 8컷 촬영 -> 베스트 4 선택 -> 인화 -> QR(사진 파일 + 영상). https://www.lemon8-app.com/@kubpulooklikedog/7381494194277237265?region=us
- 싱가포르 지점: 컷당 8초, 4컷 레이아웃에 총 8컷, self-timer 버튼 있음, 4장 선택, 이 부스는 재촬영 불가(다른 부스는 4컷 전부 재촬영 가능). https://www.lemon8-app.com/@yuntunmiann/7179654687795331585?region=sg
- 싱가포르 아이돌 프레임: 구매당 8컷, 클리커(리모컨)로 직접 촬영 가능. https://www.lemon8-app.com/@oatmilkcooffe/7314908868981621249?region=sg
- 포토이즘 앱 리뷰: "촬영 컷 수를 고를 수 있다"는 사용자 언급 1건(컬러드 기준인지 불명). https://apps.apple.com/kr/app/photoism-%ED%8F%AC%ED%86%A0%EC%9D%B4%EC%A6%98/id6747059622
- 한국 가이드: "photoism 박스(컬러드 포함) 약 10컷"이라는 잘린 문장 1건(cboard 검색 스니펫, 원문 403이라 확인 못 함).
- 포토이즘 라인: Studio(리모컨으로 직접 촬영, 전신/넓은 룸), Box(거리형 무인), Colored(컬러 배경). 흑백 감성 + "실물 느낌"이 브랜드 이미지. https://namu.wiki/w/%ED%8F%AC%ED%86%A0%EC%9D%B4%EC%A6%98
- 자체 스트로브 조명으로 "또렷하고 환한" 인상. 6~8컷 찍고 4컷 고르는 일반 흐름은 이 카테고리 설명이며 포토이즘 전용 수치는 아님. https://www.seoulwindow.com/en/guides/korean-photo-booth-brands/

### 인생네컷
- 결제 화면에서 "모바일 사진전송 QR코드" 옵션을 체크해야 사진·영상을 받는다. 촬영일 포함 3일 보관. https://www.korea-iphone.com/blog/xiyiGTrcsczj.html
- 영상 = "사진을 촬영하기 전까지의 움직임"이 담긴 영상. 같은 출처.
- 싱가포르 지점 후기: 컷 사이 약 10초. 8컷 포맷이면 전부 보관 가능하다는 후기도 있음. https://www.lemon8-app.com/salahara/7191830491794768386?region=sg (검색 요약 기준, 원문 미열람)
- 한국 기사: "비프음 후 10초 안에 포즈", 전체 약 1분(4컷 기준). https://www.koreaherald.com/article/10503226
- 앱: 프레임을 앱에서 미리 고르고 장바구니 -> 키오스크에서 QR로 결제/촬영 시작. 앱 프레임은 리모컨 촬영 미지원이라는 불만(2022). https://apps.apple.com/KR/app/id1579064841

### 하루필름/포토시그니처 차이
- 하루필름: 효과가 최상급, 프리쿠라 느낌. 포토시그니처: 3/4/6컷, 매달 새 프레임, 흑백 유명. https://gogohanguk.com/de/blog/fotoautomaten-in-korea

## 5. 8->4 선택 UX와 불만
- 4장 선택이고 재촬영 없음(포토이즘 SG), 일부 부스는 전체 재촬영 또는 1회 재촬영. 위 출처들.
- 하루필름은 선택 후 프레임/스티커 단계가 이어진다 (harufilmusa).
- 선택 시 "칸마다 선택"하는 6컷식 UI에서 시간이 모자라 원치 않는 사진이 **자동으로 들어갔다**는 유튜버 불만. 선택에 제한시간이 있다는 직접 증거(영상 자막, 모호함). https://www.youtube.com/watch?v=T_pIL2pWm1c
- 같은 컷을 두 번 고를 수 있는지, 탭 순서가 곧 배치 순서인지: **확인 못 함.** Creatrip은 "컷 선택 후 순서를 정한다"고만 한다. creatrip 위.
- 포토이즘 앱 리뷰: 고른 컷만이 아니라 **전체 컷** 영상을 원한다는 요청. 위 앱스토어.
- 일반 불만: 대기시간 1시간+, 프레임 독점 촬영, 현금 전용, 시간 제한 때문에 꾸밀 시간이 부족해 앱(MY네컷)이 "시간 제약 없음"을 내세움. https://www.kbanker.co.kr/news/articleView.html?idxno=213843 , 싱가포르 위.

## 6. 우리 앱 권고
부스 규칙은 "제한시간이 있어 긴장감이 있고 결과에 만족 못 하면 재촬영/재선택이 번거로움"이 핵심이다. 우리는 폰 + 비동기이므로 시간압박을 느슨하게 가져간다.

1. **총 8컷, 컷당 타이머 기본 8초** (부스 8~10초 범위. 실측 근거 약함) [추정]. 설정에서 5/8/10초. 첫 컷 전 카운트 3초 정도를 더 둔다 [추정].
2. **자동 연속 촬영.** 비프음(끌 수 있게) + 큰 숫자 카운트다운 + 상단에 `3/8` 진행 표시. 직전 컷은 작은 썸네일로만 잠깐 보인다 [추정: 화면 근거 없음].
3. **선택은 8컷 그리드에서 4장 탭. 제한시간 없음**(부스의 자동 채움 불만 회피). 탭 순서 = 배치 순서, 번호 배지 표시, 같은 컷 중복 선택은 금지(근거 없음, 우리 규칙) [추정].
4. **재촬영:** 컷 개별 재촬영은 없고 세션 전체 다시 찍기 1회 허용 [추정]. 부스 불만(재촬영 불가)을 완화.
5. **셀럽 프레임 방식 차용:** A의 컷아웃을 B 촬영 화면에 반투명 고스트로 띄워 위치/크기를 맞추게 한다. 부스가 모니터에 셀럽을 띄우는 것과 같은 역할. 얼굴 여백 부족 문제(epickor)를 피하려고 A 컷아웃 크기/위치를 조절 가능하게 한다.
6. **비동기 선택:** A는 8컷 중 4컷을 골라 보내고, B도 자기 8컷 중 4컷을 고른다. 최종은 쌍(pair)으로 짝지어진 4컷(1대1)으로 한다: A의 선택 순서 i번째 컷과 B의 i번째 컷을 같은 칸에 합성 [추정]. B가 A의 컷마다 맞춰 찍을 수 있도록 B 촬영 중 고스트는 A가 고른 4컷 순서대로 바뀌게 하는 안도 가능하나 컷 수가 8이면 8컷 중 4컷만 쓰이므로 B는 8컷 전부 4컷 고스트를 돌려가며(컷 1,2 -> A1 ... ) 쓰는 안이 단순하다 [추정, 결정 필요].
7. **보정:** 선택 후 0~4단계 슬라이더(뽀샤시) + 흑백/웜/쿨. 부스에서 보편적 [근거 약함, seoultourism].
8. **QR/링크:** 최종 이미지 + 8컷 전체 세션 영상(앱 리뷰의 요청). 링크 만료는 3일 이상(부스 불만이 10시간~24시간). 영상은 "셔터 전 움직임" 포함이 부스 방식.
9. **피할 것:** 선택 단계 타이머, 자동 채움, 컷 수 고정이면서 재촬영 불가, 광고성 포도 같은 게이미피케이션(우선순위 낮음), 현금 같은 결제 마찰, 포토이즘 로고/아이돌 이미지 사용.

## 빌드 스펙 (요약)
- `shots=8`, `shotSeconds=8`(설정 5/8/10), `preCount=3` [추정]
- 촬영: 거울 미리보기 + 숫자 카운트 + `n/8` + 직전 컷 썸네일 + 비프 on/off
- B 촬영: A 컷아웃 고스트(드래그/핀치로 위치·크기 조절)
- 선택: 8컷 그리드, 4장 탭, 순서 번호, 시간 제한 없음, 중복 금지
- 재촬영: 세션 전체 1회
- 보정: 슬라이더 0~4 + 흑백/웜/쿨, 합성 전 사람 레이어만
- 출력: 4컷 이미지 + 세션 영상, 링크 3일+
- 미해결 [사용자 결정]: B의 4컷 배치 방식(1대1 vs A 컷 순환), 컷당 초
- 미확인(현장/영상으로 확인 필요): 포토이즘 선택 UI·시각 정체성·셀럽 프레임 화면 구성. 실제 부스 영상 녹화나 photoism.co.kr 스크린샷이 필요하다.
