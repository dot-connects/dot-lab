## 1. 필터 -> Canvas 파라미터 [추정 출발값]
부스 공통 옵션: 원본 / 뽀샤시(뷰티) / 흑백 / 톤(웜·쿨·필름). 우리: **원본, 뽀샤시, 흑백** + 선택 웜, 쿨, 필름.
적용: 합성 전, 사람 컷아웃 레이어에만 적용. **ctx.filter는 iOS Safari 미지원/불안정 -> ImageData 픽셀 루프(또는 WebGL)가 기준 구현.**
통일 방법: 256 엔트리 LUT(채널별 곡선) + 3x3 채널 매트릭스로 대부분 표현, 글로우/스무딩/그레인만 별도 패스. 강도 슬라이더 0-100%는 원본과 선형 블렌드.

### 뽀샤시 (밝고 부드럽고 몽환적)
시각: 전체 밝음, 그림자 들림(검정이 회색), 저대비, 하이라이트 번짐, 피부 매끈, 핑크/복숭아 기운.
| 항목 | 값 |
|---|---|
| 노출 | rgb x1.12 후 clamp |
| 블랙 리프트 | out = 28 + in*(227/255) |
| 감마 | out = 255*(in/255)^0.85 |
| 대비 | (v-128)*0.88+128 |
| 채도 | x1.05 |
| 틴트 | R x1.03, G x0.995 + 그림자 핑크 가산 (R+6, G+2, B+4) |
| 글로우 | 휘도>190 추출 -> 가우시안 블러 반경 셀폭의 약 2.5% (14px) -> screen 합성 alpha 0.35 |
| 스킨 스무딩 | 원본과 블러(반경 ~3px) 블렌드 0.35, 차이 |diff|>18 픽셀(눈/입)은 가중 0.1 |
| 그레인 | 없음 |
간이판 ctx.filter: `brightness(1.12) contrast(0.88) saturate(1.05)` + `globalCompositeOperation='screen'`, `globalAlpha=0.35`, `filter='blur(14px) brightness(1.2)'`로 한 번 더 그리기. 상한: 글로우 0.35, 스무딩 0.45 (넘으면 기름 낀 얼굴).

### 흑백 (포토그레이식) [추정]
시각: 중성 그레이(틴트 없음), 하이라이트 하얗게, 그림자 깊게, 중간 대비 높음, 약한 필름 그레인.
| 항목 | 값 |
|---|---|
| 그레이스케일 | L = 0.30R + 0.60G + 0.10B (빨강 비중 올려 피부 밝게. 표준은 0.2126/0.7152/0.0722) |
| 노출 | x1.06 |
| S-커브 점 | (0,0) (64,52) (128,132) (192,205) (255,255) |
| 그레인 | 가우시안 sigma 7 (0-255), 중간톤 최대 극단 0.4배, 셀별 시드 고정(깜빡임 방지) |
| 비네팅 | 가장자리 -8% (선택) |
| 소프트 변종 | 위 + 글로우 0.2 + 블랙 리프트 12 |
간이판: `grayscale(1) contrast(1.15) brightness(1.06)` + 128x128 노이즈 패턴 overlay alpha 0.08.

### 웜 / 쿨 / 필름 [추정]
| 이름 | 파라미터 |
|---|---|
| 웜톤 | R x1.06, B x0.92, 노출 x1.05, 채도 x1.05 |
| 쿨톤 | R x0.94, B x1.07, 그림자 B+5, 노출 x1.04, 채도 x0.98 |
| 필름 | 블랙 리프트 14, 하이라이트 상한 245, R x1.04 B x0.96, 그림자 청록(R-3,G+2,B+4), 그레인 sigma 5, 채도 x0.92, 글로우 0.15 |

## 3. 부스 UX (일반 지식 + 앱 요약 [추정], 실제 스크린샷은 못 찾음)
- **카운트다운:** 3-2-1 큰 숫자(화면 70%), 바뀔 때 scale 1.3 -> 1.0 + 페이드. 3/5/10초 옵션(플픽도 설정 제공).
- **플래시:** 흰 오버레이 opacity 1 -> 0, 150ms. 셔터음은 WebAudio 노이즈 버스트 약 60ms로 합성 가능(파일 불필요). iOS 무음 모드 주의 -> 소리는 부가 요소.
- **포즈 가이드(컷마다 한 줄):** 1 "둘 다 브이!", 2 "서로 쳐다보기", 3 "손가락 하트 반쪽씩", 4 "마음대로 웃겨!". 원격이라 각자 찍어도 합쳐지는 포즈(반쪽 하트, 같은 표정) 권장. 유행: 루피 피스, 갸루 피스, 콩순이.
- **리테이크:** 부스는 N컷 중 4컷 선택. 우리: 6~8컷 찍고 4컷 고르는 방식이 부스 느낌, 최소안은 컷당 1회 재촬영.
- **저장/공유:** 완성 스트립 크게 + 버튼 3개(저장, 공유, 다시 만들기). QR은 원격 친구 초대(스캔 -> 방 입장)에 사용.
- **귀엽고 깔끔한 법 [추정]:** 크림/흰 배경 + 포인트 1색(핑크 #ff7eb6), pill 버튼, 큰 radius(16-28px), 부드러운 그림자, 화면당 CTA 1개, 마스코트는 작은 하트/별 정도로 절제.
- **카피 톤:** 반말 친근 + 짧게 ("같이 찍자!", "준비됐어?", "짠, 완성!"). 에러도 "앗, 카메라가 안 켜져. 권한 허용해줘".

## 4. 2025-26 트렌드 (확인된 범위)
- 확인: 아이돌/브랜드/게임 콜라보 프레임, 지점 한정 프레임, 유저 제작 프레임, 절취선·투명 필름 포맷, Y2K 프리쿠라 재유행, 포즈(루피/갸루/콩순이 피스).
- 일반 패션(코케트 리본, Y2K 메탈릭/나비 핀, 필름 그레인)은 프레임 소재로 적합하나 네컷 직접 근거는 아님.
- 못 찾음: 2025-26 연도 명시 기사, 포토그레이 수치 후기. 운영자가 실제 부스 사진 몇 장을 주면 그 옆에서 튜닝하는 게 가장 정확.

## 빌드 리스트
**필터:**
1. 원본: 무변경.
2. 뽀샤시: exposure 1.12, black lift 28, gamma 0.85, contrast 0.88, sat 1.05, R x1.03 + 그림자 핑크, glow 임계190/반경14px/alpha .35, smooth .35.
3. 흑백: L=0.30R+0.60G+0.10B, exposure 1.06, S-curve (64,52)(128,132)(192,205), grain sigma 7 시드 고정.
4. 웜 / 5. 쿨 / 6. 필름: 위 표. 전부 강도 슬라이더로 원본과 블렌드.
**프레임 1차:** 블랙, 화이트, 파스텔 핑크, 스카이 블루, 체크, 필름 스트립. 설정 객체 + 장식 함수 5개.
**UI 톤:** 크림 배경 + 핑크 포인트 1색, pill 버튼, 큰 radius, 화면당 CTA 1개, Jua 제목 + Gowun Dodum 본문, 반말 친근 카피, 거대 카운트다운 숫자 + 흰 플래시 150ms, 컷별 포즈 한 줄.
