## 흐름
```
보낸 사람(A)                                  받은 사람(B)
1. 링크 열기 → 카메라 → 4컷 촬영              4. 링크 열기 → 바로 카메라
   (옆에 "친구 자리" 표시, 컷마다 직전 2초)      칸마다 A가 이미 서 있고 B는 누끼로 옆에 섬
2. 올리기 → 링크 생성 → 공유                  5. 4컷 촬영 → 올리기
3. (기다림) 같은 링크를 다시 열면 상태 보임    6. 완성 → 배경·프레임 고르기 → 저장
                      둘 다 끝나면 A, B 모두 같은 링크에서 저장 가능
```
- 배경: 보낸 사람 배경 / 받은 사람 배경 / 흰색 / 준비된 배경(보라 부스 등). 마지막에 고르고, 바꿔도 다시 찍지 않는다.
- 프레임: 블랙·화이트·핑크로 시작. 띠 아래 "따로 같이 네컷 · 날짜 · 두 지명(선택)".
- 저장물: 네컷 이미지(JPG), 움직이는 네컷 영상(MP4, 네 칸이 각자 2초씩 반복).
- 링크는 7일 뒤 만료(사진·영상 자동 삭제). 회원가입 없음.

## 실측 (실험 페이지 `spike/`, 운영자 폰 SM-F971N Android 17, 10-26)
| 환경 | 카메라 | 누끼(selfie_segmenter, GPU) | 2초 녹화 | 저장 |
|---|---|---|---|---|
| 스레드 인앱 | ✅ 960×720 | ✅ 39ms ≈ 25fps | ✅ mp4 ~0.6MB | ❌ 공유·다운로드·길게 누르기 전부 |
| 인스타 인앱 | ✅ | ✅ | ✅ | ❌ (스레드와 같음) |
| 카톡 인앱 | ✅ 3초 | ✅ 55ms ≈ 18fps | ✅ | ❌ (blob·https 모두) |
| 크롬 | ✅ (떠 있는 앱을 끄면) | — | — | ✅ https 파일 다운로드 |
- 인앱 → 크롬 넘기기 됨: 카톡 `kakaotalk://web/openExternal?url=`, 안드로이드 `intent://…;package=com.android.chrome`.
- 크롬 권한 창은 화면 위에 떠 있는 앱이 있으면 막힌다(안드로이드 보안). 안내 문구로 처리.
- 카메라는 가로 4:3 프레임을 준다. 자르지 않고 원래 비율로 보여 줘야 얼굴이 작게 나온다(운영자 지적으로 수정).
- 처음엔 스레드에서 카메라 요청이 응답 없이 멈췄다가 다시 해 보니 됐다 → 5초 응답 없음 안내 + 크롬 넘기기를 남겨 둔다.
- 줌·탭 초점은 폰·카메라마다 다르다(브라우저가 주는 capability 만큼만). 실험 페이지 "줌·초점" 줄로 확인. 미확인: iPhone.

## 결정
1. **찍기는 앱 안에서, 저장은 크롬에서.** 인앱 결과 화면의 저장 버튼 = "크롬에서 열어 저장하기"(같은 링크). 크롬이면 바로 저장.
2. **저장소 = Cloudflare R2 + Worker** (운영자 10-26 승인, 운영자 명의 무료 계정). 친구 링크와 크롬 저장 둘 다 이것 때문에
   필요하다. 7일 lifecycle 삭제.
3. **둘 다 누끼.** 배경을 마지막에 고르기 위해. 합성은 화면 쪽(폰)에서 한다. 서버는 파일만 맡는다.
4. **좌우반전은 옵션**(전면 기본 켬, 후면 기본 끔). 미리보기·사진·영상 모두 화면에 보인 그대로 저장한다.
5. **전면·후면 전환, 핀치 줌, 탭 초점**은 폰이 지원하면 켠다.

## 데이터 (한 사람 4컷 기준, 추정)
| 컷마다 | 형식 | 크기(추정) | 쓰임 |
|---|---|---|---|
| 원본 사진 | JPG | ~150KB | "내 배경" 선택 시 바탕 |
| 누끼 사진 | PNG(알파) | ~300KB | 다른 배경 위에 얹기 |
| 원본 2초 | MP4 | ~500KB | 움직이는 네컷, 내 배경 |
| 누끼 2초 | MP4, 단색(초록) 바탕 | ~400KB | 움직이는 네컷, 다른 배경 — 합성 때 크로마키로 뺀다 (MP4는 알파가 없다) |
→ 한 사람 약 5.5MB, 한 링크(둘) 약 11MB. 무료 10GB면 7일 동안 약 900링크. 넘으면 GB당 월 $0.015.

## 서버 (Worker, 최소)
- 배포: https://dot-lab-booth.dotconnects.workers.dev (10-26, 서브도메인 dotlab 은 이미 사용 중이라 운영자 승인 대안 dotconnects). R2 `dot-lab-booth`, lifecycle `expire-7d` (s/, 7일).
- 계획 리뷰 뒤 바뀐 점: join 없음 — B 는 토큰 해시 폴더에 올리고 `done` 이 자리를 차지(먼저 끝낸 친구). IP당 생성 제한·링크당 용량 누적은 뺌(12파일 × 3MB 상한 + 운영자 Class A 알림).
- `POST /s` → 새 링크 `id`(추측 불가 22자) + 보낸 사람 쓰기 토큰.
- `POST /s/:id/join` → 받은 사람 쓰기 토큰(첫 1명만. 이미 있으면 "이미 누가 찍었어요").
- `PUT /s/:id/{a|b}/{cut}-{kind}` (토큰 필요) / `GET` 같은 경로 / `GET /s/:id` 상태(a 완료, b 완료, 만료일).
- 제한: 파일당 3MB, 링크당 30MB, 링크 생성 IP당 시간당 N회. 청구 알림 $1.
- 저장 버튼(이미지·영상)은 b 완료 후에만 보인다. 영상 합성은 저장하는 폰(크롬)에서 canvas + MediaRecorder로.
- 배포: wrangler. 운영자가 `! npx wrangler login` 한 번. 시크릿·토큰은 repo 에 넣지 않는다.

## 화면
1. 첫 화면: 프로모션 시안 첫 화면 축약 + [먼저 찍기] (받은 사람은 "OO가 옆자리를 비워 뒀어요" + [바로 찍기])
2. 촬영: 원래 비율 카메라 + 친구 자리 점선(A) / A 누끼가 서 있음(B) · 3초 카운트다운 · 1/4 · 썸네일 · 반전·전후면·줌
3. 올리는 중 → 공유(A) / 완성(B)
4. 완성: 띠 미리보기 + 배경·프레임 고르기 + 저장 2개(인앱이면 크롬으로)
5. 만료: "7일이 지나 사라졌어요" + [새로 찍기]
