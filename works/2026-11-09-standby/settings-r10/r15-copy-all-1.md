## 규칙

1. 문장은 모두 해요체. 이름표(줄 제목·값)는 명사로 끝나도 돼요.
2. 할머니·할아버지도 아는 말만 써요 (다이얼 → 시계판, 잔상 → 화면 자국, 발열 보호 → 뜨거워지면 화면 어둡게).
3. 한 개념에 낱말 하나: 추가 / 빼기(목록에서) / 지우기(없애기) / 꾸미기(모양) / 바꾸기(교체) / 글꼴 / 색 / 페이지 / 기본 페이지 / 자동으로 켜기·끄기 / 허용.
4. 앱 이름은 어디서나 "Stand Screen" (문장 안에서도). 앱이 나타나는 것은 "켜져요"라고 써요 ("떠요" 안 씀).
5. 어떻게 동작하는지가 아니라 그래서 어떻게 되는지를 말해요.
6. 숫자·단위는 쓰지 않아요 (%, 도, lux, 굵기 값). 남기는 숫자: 밤 시간, 집중/휴식 분, 꺼지는 시간, 사진 넘김 간격, 미리 밝히기·밝아지는 시간, 무드등 자동 끄기, D-day 날짜, 버전, 개수(○개·○장).
7. 막대는 양 끝에 말: 가늘게 ↔ 굵게, 작게 ↔ 크게, 어둡게 ↔ 밝게, 조금만 어두워도 ↔ 캄캄할 때만, 비치게 ↔ 진하게, 각지게 ↔ 둥글게, 옅게 ↔ 짙게.
8. 줄 제목은 되도록 12자 안, 아래 설명은 한 문장.
9. 제목·버튼·이름표에는 마침표 없음. 설정 화면의 문장(설명·안내·확인 창·토스트)은 마침표로 끝나요. Stand Screen 화면의 카드 문구는 짧은 이름표로 보고 마침표를 안 붙여요.
10. 버튼은 동사 (켜기, 고르기, 추가, 지우기, 허용하기). 고르는 값은 상태 (끔, 켜짐).
11. 안 될 때는 다음에 할 일을 말해요 ("…없어요. 다른 이름으로 찾아보세요.").
12. 읽어주기(접근성) 이름표는 누르면 일어나는 일을 말해요 ("○○ 설정 열기").
