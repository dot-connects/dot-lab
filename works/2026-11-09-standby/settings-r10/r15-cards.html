StandBy 카드 다듬기 시안

모든 카드를 칸 크기 5종 × 기기 6종으로 다시 봤습니다. “현재”는 실제 렌더 화면, “제안”은 같은 칸 크기로 그린 시안입니다. 치수는 모두 dp.

1. 타이머 — 어떤 칸에서도 원형

지금은 칸 모양에 따라 3가지로 갈립니다(Cards.kt 575~612줄): 작은 칸은 원이 없고, 가로 칸은 원 안에 “집중” 글자만 있고 숫자가 밖에 있습니다. 제안은 하나입니다 — 원 + 원 안 숫자는 늘 같고, 버튼만 자리를 옮깁니다. 버튼은 둥근 네모(모서리 = 높이의 30%)로 작게: 높이 = 짧은 변 × 13% (36~56dp), 시작/멈춤은 가로 1.6배. 주황 호 = 60분 눈금에서 남은 시간, 멈춰 있을 때 원을 돌려 분을 정하는 것은 그대로입니다.

2. 다른 카드 — 큰 칸에서 글자가 안 커지는 문제

공통 원인 하나: 본문 15dp · 보조 13dp가 칸 크기와 상관없이 고정입니다(Kit.kt 131~132줄). 작은 칸에서는 맞지만, 화면 전체 칸에서는 내용이 한쪽에 작게 몰리고 나머지가 빕니다. Flip·바형 폰의 프리셋 화면과 시계·사진·미디어 카드에서는 고칠 것을 찾지 못했습니다.

3. 작은 것들낮음

시안 없이 같은 규칙(글자를 칸에 맞춰 키우기, 묶음을 가운데로)으로 고칠 수 있는 것.

3. 알림 카드 — 밀어서 지우기 켜고 끄기

지금은 알림을 옆으로 밀면 지워져서 페이지 넘기기와 겹칩니다. 「모두 지우기」를 없애고, 머리에 밀어서 지우기 버튼을 둡니다. 꺼져 있으면 옆으로 미는 건 늘 페이지 넘기기. 켜면 그 카드 안에서만 알림을 밀어 지우고, 30초 동안 밀지 않거나 화면이 꺼지면 저절로 꺼집니다.

4. 타이머 — 작은 칸에서도 집중·휴식 구분, 길게 눌러 바꾸기

집중이 끝나면 휴식, 휴식이 끝나면 집중으로 번갈아 갑니다. 작은 칸에서도 한눈에 구분되게 색 + 글자를 같이 바꿉니다: 집중 = 주황 호 + "집중", 휴식 = 초록 호 + "휴식". 원을 길게 누르면 집중↔휴식이 바뀝니다(멈춰 있을 때, 짧은 진동으로 알려 줌). 길게 누르기는 원 위에서는 페이지 설정 열기보다 먼저 받습니다.

5. 타이머 끝 알림 — 소리·진동 들어 보기

버튼을 누르면 소리가 나고, 폰에서 열면 진동도 같이 옵니다(브라우저가 진동을 막으면 소리만). 무음·진동 모드에서는 진동만 합니다. 하나를 고르시면 그걸 기본으로, 설정에서 "소리+진동 / 진동만 / 끄기"를 고를 수 있게 합니다.

6. 타이머 앱 알림 — 스탠드 스크린이 닫혀 있어도

타이머를 켜면 알림 칸에 도는 동안 알림이 고정으로 뜹니다(남은 시간이 1초마다 줄고, 멈춤·초기화 버튼). 시간이 다 되면 스탠드 스크린이 닫혀 있어도 폰 알람 기능으로 제때 끝 알림이 위에 크게 뜨고, 고르신 소리·진동이 3번 울립니다. 잠금 화면에도 보입니다. 스탠드 스크린이 떠 있을 때는 지금처럼 카드에서 알리고, 위에 뜨는 알림은 생략합니다.
