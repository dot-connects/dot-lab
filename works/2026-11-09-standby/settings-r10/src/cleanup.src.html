StandBy 정리 시안 — 뺄 것과 고칠 것

눈으로 보고 정하실 수 있게 실제 화면을 나란히 놓았어요. 뺄 후보 4가지에는 제 추천을, 고칠 곳 5가지에는 지금 화면과 고친 시안을 붙였어요. 화면은 모두 폴드 커버 가로(751 × 475) 기준이에요.

실제 화면 앱이 그린 그대로 · 예시 실제 화면이 없어서 코드 값으로 만든 것 · 시안 고친 뒤 모습을 그린 것

  • 빼기

A. 뺄 것 후보

빨간 테두리가 빼자고 하는 쪽이에요. 빼도 이미 그 값을 쓰던 설정은 가장 가까운 남는 값으로 바꿔 줘요.

A1. 시계 효과 — 무지개 · 유리 vs 단색 · 두 색 · 번짐

남길 것

뺄 후보

더하는 것무지개는 장난스러운 색, 유리는 반투명 숫자에 밝은 테두리를 줘요.

드는 값유리는 숫자 속이 60%만 칠해져서 검정 위에서 어두운 남색이 돼요. 1~2 m 밖에서는 테두리만 보여요. 무지개는 고른 색이 무시되고 테마 색과도 안 맞아요. 둘 다 밤에는 어차피 단색으로 바뀌어요.

빼기무지개와 유리를 빼요. 색을 섞고 싶으면 두 색, 빛나는 느낌은 번짐으로 충분해요.

바뀌는 코드 model/Config.kt Effect에서 RAINBOW · GLASS 삭제 → ui/clock/TimeText.kt(무지개 셰이더, 유리 테두리 · glassStroke), ui/clock/FloatFace.kt(GLASS 분기) 정리 → settings/ConfigCodec.kt에서 모르는 값은 SOLID로 읽기. 설정 화면 settings/ClockScreens.kt 효과 고르기는 enum을 그대로 써서 자동으로 3칸이 돼요.

A2. 시계 너비 % — 좁게 · 기본 · 넓게

좁게 · 넓게는 실제 화면이 없어서, 기본 화면의 숫자를 앱과 같은 방식(글자를 가로로만 늘리기)으로 늘려 만들었어요.

더하는 것숫자의 가로 폭을 70~130%로 바꿔요.

드는 값숫자는 이미 화면 폭에 꽉 맞춰져 있어서, 넓히면 폭은 그대로고 키만 낮아져요. 좁히면 획이 가늘어지고 옆이 비어요. 어느 쪽도 멀리서 더 잘 보이지 않아요. 글꼴 고르기(좁게 · 둥글게 등)와 하는 일도 겹쳐요.

빼기조절 막대만 빼요. 시계마다 맞춰 둔 기본 비율(디지털 94%, 아날로그 115%)은 안에 그대로 둬서 지금 모습이 바뀌지 않아요.

바뀌는 코드 settings/ClockScreens.kt의 "너비" SliderRow 한 줄 삭제. ClockStyle.widthPct 필드와 TimeText.kt는 그대로 두고, settings/Migrations.kt에서 저장된 값을 시계별 기본값으로 되돌려요.

A3. 테마 — 촛불 vs 무드등

촛불 (뺄 후보)
무드등 (남김)
낮 — 위젯 페이지
낮 — 시계
낮 — 책상 보드
밤 — 위젯 페이지
밤 — 시계
밤 — 책상 보드

12장 모두 실제 화면이에요.

더하는 것촛불은 무드등보다 숫자가 한 단계 가늘고, 바탕이 조금 더 어둡고, 빛이 아래에서 올라와요.

드는 값낮에는 나란히 놓아야 겨우 구분돼요. 밤에는 두 테마 모두 같은 밤 색으로 바뀌어서 숫자 굵기 말고는 똑같아요. 테마 고르기에 거의 같은 칸이 두 개 생겨요.

합치기무드등 하나로 합쳐요. 촛불을 쓰던 설정은 무드등으로 넘겨요. 가는 숫자가 좋으면 시계 글꼴에서 "얇게"를 고르면 돼요. 밤 화면의 "촛불 색"은 테마와 별개라 그대로예요.

바뀌는 코드 model/Config.kt Theme.CANDLE 삭제 → ui/theme/ThemeTokens.kt의 CANDLE 값, ui/theme/Theme.kt 두 줄 삭제 → settings/Migrations.kt에서 "CANDLE" → MOODLIGHT. NIGHT_INK(밤 색)는 건드리지 않아요.

A4. 배경 — 그래파이트 · 미드나잇 · 앰버 · 오로라 vs 테마 기본 · 순검정 · 사진 흐림 · 단색

남길 것

뺄 후보

순검정과 단색은 실제 화면이 없어서 같은 판 배치를 코드 값(판 = 흰색 7%)으로 그렸어요. 기본 테마는 바탕이 원래 검정이라 테마 기본과 순검정이 거의 같아 보여요.

더하는 것판 뒤로 은은한 색 빛이 깔려요. 미드나잇은 파랑, 앰버는 주황, 오로라는 청록과 보라예요.

드는 값그래파이트는 테마 기본과 구분이 거의 안 돼요. 나머지 셋은 판이 화면을 거의 다 덮어서 가장자리에만 색이 비쳐요. 테마 10개 × 배경 9개라 고를 건 많은데 달라지는 건 적어요. 색을 원하면 단색이나 색이 있는 테마(무드등 · 하늘)로 돼요.

빼기네 가지 모두 빼요. 쓰던 설정은 테마 기본으로 넘겨요. 하나만 남긴다면 다른 것과 가장 다르게 보이는 오로라예요.

바뀌는 코드 model/Config.kt BoardBg에서 4개 삭제 → ui/theme/Primitives.kt PRESETS 정리(그래파이트 값은 "사진 흐림"에 사진이 없을 때 바탕으로 쓰이니 값만 남겨요) → settings/Migrations.kt에서 없어진 값은 THEME으로. 설정 화면 settings/HomeScreen.kt 배경 칩은 enum을 그대로 써서 자동으로 줄어요. 참고: "시간 따라"는 코드에 해질녘 색 한 벌만 들어 있는 반쯤 만든 상태예요. 이번 범위는 아니지만 같이 정할 만해요.

B. 고칠 것 (지금 → 시안)

왼쪽이 지금 앱이 그리는 화면, 오른쪽 파란 테두리가 고친 모습이에요.

B1. 플립 시계 테마인데 전체 화면 시계에 플립 타일이 없어요

같은 테마의 카드에서는 이미 이렇게 타일 위에 숫자가 놓여요(실제 화면). 전체 화면 시계도 같은 모양으로 맞춰요. 밤에는 지금처럼 타일 없이 숫자만 남겨요.

바뀌는 코드 ui/clock/DigitalFaces.kt의 디지털 시계가 숫자를 직접 그려서(p.drawHm) 타일 규칙을 안 거쳐요. 테마 숫자 모양이 FLIP이고 글꼴이 테마 기본 · 효과가 단색 · 낮일 때(카드와 같은 조건)는 ui/theme/Primitives.kt의 FlipDigits로 그리게 해요(지금 private → internal). 숫자 폭 계산은 타일 기준(타일 0.62 · 콜론 0.35 · 간격 0.06 em)으로. "10:58"처럼 네 자리면 타일이 20%쯤 작아져요.

B2. 모듈러 페이지의 날씨 칸이 반쯤 비어 있어요

날씨 칸이 크기에서는 시간 예보 2칸을 빼고 기온을 칸 높이에 맞춰 키워요(글자 높이 약 50 → 100 dp). 넓은 칸에서는 지금처럼 시간 예보가 나와요.

일정 칸세 줄을 작게 쓰는 대신 다음 일정 하나만 시각 · 제목을 크게 쓰고, 나머지는 "외 3개"로 줄여요. 1 m 밖에서도 읽혀요.

바뀌는 코드 ui/cards/Layouts.kt weatherShape: 이 칸(270 × 197 dp)은 지금 WIDE(왼쪽 42%에 기온, 오른쪽에 시간)로 가요. 폭 300 dp 미만은 숫자만 크게 쓰는 모양으로 보내요. ui/cards/Cards.kt WeatherCard에서 그 모양일 때 기온 높이 = 칸 높이 − 머리 두 줄. 같은 파일 AgendaCard: 칸 높이 220 dp 미만이면 일정 1개(시각은 Hero, 제목 26 dp) + "다음 … · 외 n개" 한 줄.

B3. 라이브 화면 오른쪽 40%가 비고, 단계에 시각이 없어요

바뀐 점남은 시간을 세로 가운데로 올리고 더 키웠어요. 단계는 오른쪽 끝까지 써서 글자를 15 → 24 dp로 키우고, 지난 단계에는 바뀐 시각, 도착에는 예상 시각을 붙였어요.

알아 둘 점배달 앱 알림에는 단계별 시각이 들어 있지 않아요. 그래서 지난 단계 시각은 "StandBy가 단계가 바뀌는 걸 본 시각", 도착은 "지금 + 남은 분"으로 만들어요. 아직 안 온 단계(픽업)는 비워 둬요.

바뀌는 코드 ui/screens/Overlays.kt LiveScreen: 가로일 때 왼쪽 열을 머리(위) + 숫자(남은 높이의 가운데)로, 오른쪽 열 timeline은 폭을 다 쓰고 StepRow에 시각 칸(오른쪽 정렬) 추가, 단계 글자 크기 상한 19 → 24 dp. ui/state/State.kt LiveActivity에 stepTimes(단계별 시각, 없으면 null)와 etaAt 추가. platform/Listener.kt에서 진행 단계가 바뀔 때 시각을 적어 두고, 값이 "12분" 꼴이면 도착 예상을 계산해요.

B4. 디지털 시계의 오른쪽 정보가 화면 끝에 붙어요

왜 고치나잔상을 막으려고 화면 전체가 1분마다 3 dp씩 움직이는데, 여백이 그보다 작으면 "6:30" 끝이 잘려요. 시안은 실제 화면의 숫자와 정보 묶음을 그대로 줄여서 만들었어요.

바뀌는 코드 ui/clock/DigitalFaces.kt 디지털 시계의 "아이폰" 배치: 쓸 수 있는 폭을 w − 1.5 × margin에서 w − 2 × margin으로(오른쪽도 여백 전체), 폭에 곱하는 × 1.03은 Sofia 글꼴(CONDENSED)일 때만. 끝으로 x0 + 숫자 + 간격 + 정보 폭 ≤ w − margin이 안 맞으면 숫자를 더 줄여요. 테마 글꼴이 넓은 터미널(모노) · 무드등에서 넘치던 게 사라져요.

B5. 끌어내림 패널의 테마 미리보기가 밤에는 다 똑같아 보여요

바뀐 점패널과 밝기 막대는 밤 색 그대로 두고, 테마 미리보기 칸만 낮 색으로 그려요. 눈이 부시지 않게 밝기를 조금 낮췄어요. 시안의 미리보기는 낮 패널의 실제 화면에서 가져왔어요.

알아 둘 점처음 보이는 세 테마(기본 · 신문 · 무드등)는 낮에도 서로 비슷한 어두운 테마예요. 옆으로 넘기면 나오는 종이 · 네온 · 하늘에서 차이가 더 커요.

바뀌는 코드 ui/screens/TopPanel.kt의 미리보기 PreviewFrame(…, night = state.night) → night = 0f, 밤일 때는 미리보기에 alpha 0.85. 함수 위 주석("previews are drawn at night too")도 고쳐요. 밤 패널 스크린샷은 기본 테마만 있어서(_sheets/brightness), 나머지 9개 테마도 찍도록 샷 목록에 추가하면 좋아요.

못 담은 것

  • 너비 좁게 · 넓게, 배경 순검정 · 단색은 실제 화면이 없어서 예시로 대신했어요.
  • 배경 비교는 기본 테마에서만 찍혀 있어요. 무드등처럼 바탕에 색이 있는 테마에서는 "테마 기본"이 다르게 보여요.
  • B1 · B2 · B3 시안은 그림이라 글꼴 굵기와 자간이 앱과 조금 달라요. 위치와 크기를 보는 용도예요.
  • 움직임(플립 넘어가는 모습, 번짐의 깜빡임)은 정지 화면이라 담지 못했어요.
