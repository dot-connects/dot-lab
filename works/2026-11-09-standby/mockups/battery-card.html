스탠드 스크린 · 배터리 카드 (B 차오름 3차)

카드 바탕이 배터리만큼 아래에서 차올라요. 큰 숫자는 %, 그 아래 한 줄은 완충 시각. 색은 따로 정하지 않고 지금 앱에 고른 테마를 그대로 따르고, 밤에는 앱의 밤 색(촛불 톤)이 돼요. 달력 크기·넓은 칸에서는 밝기와 소리를 끌어서 바로 조절해요(막대를 눌러 끌어 보세요). 1px = 1dp.

3차에서 바꾼 것

  • 수위선 뺌: 차오른 면 윗변을 28dp 에 걸쳐 흐리게 풀어 선 없이 경계만 느껴지게.
  • 지금 폰 칸: 소리·네트워크·밝기를 빼고 충전 세기·온도 두 칸만.
  • 정보 칸 통일: 아이콘 목록 대신 "작은 이름 위에 큰 값" 칸으로 모든 크기를 맞춤(폰·긴 칸·달력·넓은 칸).
  • 달력 크기: 밝기·볼륨 막대를 나란히 두고, 빈 가운데에 충전·온도.

2차에서 바꾼 것

  • 밤: 빨강 대신 앱의 밤 색 그대로(검정 바탕 + 아래쪽 호박빛, 글자 #B9A48C). 경고색도 밤엔 쓰지 않아요.
  • 테마 따라: 카드 판·글자·강조색 모두 앱 테마 값. 기본·종이·하늘 세 개로 확인.
  • 차오름: 딱 잘린 색 면 대신 아래가 진하고 위로 옅어지는 면 + 얇은 수위선. 숫자를 가로질러도 숫자가 묻히지 않아요.
  • 숫자: 아주 가는 Inter 200, % 는 위에 작게. 한글 굵은 글자와 섞여도 숫자가 주인공.
  • 조절: 큰 칸은 밝기·볼륨 막대가 바탕처럼 아래(왼쪽)에서 차오르는 같은 언어. 소리 모드는 소리/진동/무음 한 줄. 진동·무음일 땐 볼륨 막대가 흐려져요.
  • 넓은 칸: 세로 막대 둘(밝기·볼륨) + 소리 모드 + 방해 금지 스위치. 충전 곡선은 가운데.

크기별로 담는 것

  • 작은 칸 140×120: % · 완충 시각.
  • 짧고 넓은 칸 270×200: + 남은 시간, 충전 세기·온도.
  • 지금 폰 칸 198×253: + 충전 세기·온도 두 칸.
  • 좁고 긴 칸 218×419: + 여섯 칸(충전·온도·소리·밝기·네트워크·꽂은 뒤 오른 %).
  • 달력 크기 338×419: + 소리 모드 바꾸기, 밝기·볼륨 막대.
  • 넓은 칸 695×419: + 충전 곡선, 세로 막대 둘, 방해 금지.
