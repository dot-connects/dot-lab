## 한 줄
여행 날짜만 넣으면 폰 사진·영상 중 잘 나온 것만 골라, 날짜·장소별로 넘기는 여행 책과 하이라이트 영상을 만들어 준다.
일기·메모·타임라인이 있으면 넣을수록 글이 내 여행 이야기가 된다.

## 흐름
```
[폰 앱]                                              [Worker]                [AI]
1 날짜 범위 + 참고 자료(선택) + 타임라인 JSON(선택)
2 갤러리 조회: 기간 안 사진·영상, 촬영 시각·GPS·길이
3 1차 거르기(폰, 0원): 스크린샷·흐림·어두움·연사 중복 → 사진 30~40 + 영상 후보
   영상은 1~2초 간격 장면 몇 장
4 미리보기 + 시각·장소 + 참고 자료 글 ───────────→ 키 숨김·월 상한 ──→ 고르기·애매 표시·캡션·
                                                                          에세이·영상 구간
5 ← 결과 ←──────────────────────────────────────────────────────────────
6 애매한 것: 두 장 중 탭 / [다 맡기기]
7 책 조립 → 넘기는 책 / 페이지 이미지 / PDF / 하이라이트 영상 (모두 폰에서)
```

## 화면
1. **시작**: 날짜 범위(달력, 처음·끝 두 번 탭) + [참고 자료 넣기](파일 / 붙여 넣기 / 사진 찍기) + [타임라인 넣기](내보내기 순서 그림 안내).
   첫 실행엔 권한 전에 "사진은 폰을 떠나지 않아요, 작은 미리보기만 AI 가 봐요" 한 줄.
2. **찾는 중**: "사진 412 → 38 → AI 가 고르는 중" 숫자가 올라가고, 걸러진 사진이 작게 지나간다.
3. **애매한 것**(있을 때만): 두 장 나란히 "어느 쪽?", 남은 질문 수, 오른쪽 위 [다 맡기기].
4. **책**: 표지(제목·기간·대표 사진) → 날짜 장 표지(장소, 타임라인 있으면 동선 지도) → 사진·영상 + 캡션 → 마지막 에세이 →
   마지막 "여행 영상" 페이지. 옆으로 넘김. 페이지 길게 누르기 = [사진 바꾸기] [글 다시 쓰기](그 페이지만 다시 요청).
5. **내보내기**: [페이지 이미지 저장] [PDF 만들기] [영상 저장] [공유].
6. **내 책장**: 만든 책 목록(폰 저장). 다시 열기·지우기.
책 디자인(판형·글꼴·배치)은 이 spec 승인 뒤 시안 HTML 3개(폰 세로, Artifact)로 운영자가 고른다.

### 저장 전 미리보기에서 다듬기 (운영자 11-25)
책이 다 만들어진 뒤, 저장·내보내기 전 미리보기 화면에서 바로 바꾼다. 바꾸면 그 자리에서 다시 그린다(AI 다시 부르지 않음, 글 고치기 제외).

| 다듬기 | 범위 | 이유 |
|---|---|---|
| 표지 | 테마 시안 3개 중 하나 | |
| 표지 색 | **항상 바꿀 수 있음** — 테마 팔레트 + 직접 고르기. 표지 위 글자 대비는 앱이 자동으로 맞춘다(흰/먹 전환·막) | 운영자 11-25 |
| 글꼴 | 테마마다 어울리는 후보 2~3개 | 아무 글꼴이나 쓰면 배치가 무너진다 |
| 글자 크기 | 작게 / 보통 / 크게 3단 | 슬라이더는 쪽 배치를 깬다 |
| 제목·한 줄 문구 | 표지 제목, 쪽마다 한 줄 직접 고치기 | |
| 사진 빼기·바꾸기 | 쪽의 사진을 빼거나 같은 장소·시간대 다른 사진으로 | 쪽 길게 누르기와 같은 동작 |
| 사진 자르는 위치 | 사진을 끌어 보이는 부분 옮기기(얼굴·수평선 잘림) | 비율은 그대로 |
| 정보 줄 | 시각·km·날씨 같은 숫자 줄 보이기/숨기기 | |

화면 방식: **한 장씩 결정 카드**(운영자 11-25, 시안 A 시트 탭·B 쪽 위 도구 중 C 선택). 단계마다 [그대로 두기]·[다음], 위에 n/N 과 [바로 저장], 저장 전 요약 카드에서 바꾼 것을 누르면 그 단계로 돌아간다. 시안: `mockups/edit-ui/`.

색 면(진한 단색 바탕)은 표지에만 쓴다. 본문은 종이색이고 강조색은 숫자·번호에만(운영자 11-25, 기록 카드·여행 수첩 "진한 단색이 과하다").

## 실패할 때
| 상황 | 앱이 하는 일 |
|---|---|
| 사진 5장 미만 | 책 대신 "사진이 N장뿐이에요, 기간을 넓혀 볼까요?" |

| 참고 자료를 못 읽음 | 그 파일만 빼고 "못 읽은 파일: 이름" |

| 하이라이트 영상 실패 | 책은 그대로, 영상만 "다시 만들기" |

## 검증
- 테스트(틀리면 비싼 곳만): prefilter 판정, 장 나누기(시간대 포함), timeline 3형식 파서, refdocs 글 추출·날짜 찾기, Worker 상한.
- 실제로 돌려서: 운영자 폰에서 실제 여행 1건(운영자는 날짜만). 몇 장 → 몇 장, 걸린 시간, 실제 비용(원)을 숫자로 보고 + 화면 캡처.
- 통과 기준: 운영자가 책을 보고 "다른 여행으로도 한 번 더 만들어 보고 싶다".
