생성기 build_c9.py(내 scratchpad\c9). demo 3곳 1일·15곳 3일로 확인.

## 바꾼 것
- **표지 ①** 짙은 acc 섬 + 흰 동선(활 곡선, 밤사이 점선, 사진 46점), 시작·끝 번호 18, 위경도·축척, 4칸 집계(라벨 10).
- **01 지도** 사진 콜아웃 54(쪽 너비 16%) + 번호 18 + 지명 10을 위·아래 레일에 5칸씩. 섬을 더 크게(폭 300). 색인 대신 사진 이름, 아래 범례 한 줄.
- **11 정산** 시간표: 시간대별 사진 막대(최다 시각 acc) + 날 줄(장소 막대 + 번호 + 이름/첫 시각) + 장소 사이 km + 4칸 집계. 사진별 눈금은 뺌.
- **사진 쪽** 날씨 삭제 → `첫–마지막 시각 · 읍면 · 사진 n · 영상 n`, 폴리오에 섬 위치 점.
- 가장 작은 글자 9.5 단위 = 360px 폭에서 10.4px.

## 정보 쪽 계산
| 쪽 | 무엇으로 |
|---|---|
| 표지 ①·01 | 사진 위경도만 투영. 같은 장소 연속 사진 → 중심 한 점(앱: 같은 지명 또는 1.5km 안) |
| 01 콜아웃 | 장소별 사진 수 상위 10곳, 대표 사진 1장, 지명 = 역지오코딩 |
| 11 막대 | 시각별 사진 수 |

| 집계 | 46·3·9곳·214km(날 12+121+81 = 사진 위치 직선 합) |

## 어떤 경로든 — 그리기 규칙
1. 축척: 경로 bbox 맞춤, 상한 20px/km. 해안선이 칸을 다 덮으면 육지 면 생략.
2. 경로: DP 2px → 활 곡선. 28 단위 미만은 직선, 길수록 최대 18%까지 휨(몰린 점 엉킴 방지).
3. 콜아웃 최대 10, 레일당 5. 가까운 레일 → 한 점씩 옮겨 (지시선 제곱길이 + 스침 벌점) 줄면 채택 → 1D 밀어내기 → 교차 쌍 자리 바꿈. 나머지 장소는 번호만.
4. 시간표: 축 = 첫~마지막 사진 시(짝수). 줄 높이 210÷일수(쪽당 3일). 이름은 앞 이름 오른쪽으로 밀고, 막대에 안 닿으면 생략. 줄 높이 120 이상(1일)이면 장소별 목록 줄. km 는 34 단위 이상 빈 곳에만.
