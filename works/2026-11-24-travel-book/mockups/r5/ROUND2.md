# 5차 2회차 — 테마끼리 겹침 정리 (Claude 총평)

여섯 개 다 4차보다 훨씬 좋다. 문제는 **서로 닮아졌다**는 것: 거의 모든 테마가 "초대형 시각 숫자(17:40·19:05·13:30) + 214km 요약 + 코발트/노랑/주황 색면 + 1색 섬 지도"를 쓴다.
쪽 하나만 보고 어느 테마인지 알아야 한다. 아래 "소유권"을 지킨다.

| 장치 | 가진 테마 | 나머지 |
|---|---|---|
| 초대형 시각 숫자(09:42, 17:40…) | b 기록 카드만 | 다른 테마는 시각을 캡션 크기로 |
| 214km 초대형 요약 숫자 | b 기록 카드만 | 다른 테마는 숫자 요약을 작게(한 줄) 또는 자기 방식으로 |
| 큰 날 번호 01·02·03 | mag 잡지(굵게), a 여백의 책은 **가는 300 굵기**로만 | 다른 테마 금지 |
| 큰 날짜 12·13·14 | diary 일기만 | |
| 6월 달력 리캡 | diary 일기만 | b 는 다른 마지막 쪽 |
| 1색 섬 지도 | b, mag, c 각자 다른 모양으로(아래) | a·album·diary 는 지도 없음 |
| 전면 색면 | b(코발트·핑크·라임), mag(노랑+딥그린), c(토마토), diary(블러시·세이지·버터) | a·album 은 전면 색면 없음 |
| 주황 | album 의 날짜 각인 전용 | |

테마별 지시
- a 여백의 책: 날 여는 쪽 숫자 01/02/03 을 Inter Tight 200~300 가는 굵기로(지금 900 흰 숫자는 잡지와 겹침). 마지막 쪽 214 초대형·섬 지도 빼고, 마지막 한 장 사진 + 작은 색인(9곳·시각 목록) 같은 조용한 끝으로. 표지① 왼쪽 아래 잘린 사람 머리가 어색 — 크롭 조정.
- b 기록 카드: 색 조합 기본을 코발트 #2F6FD6 · 더스티 핑크 #D59A9A · 라임 #CFE86B(노랑은 잡지 몫)로. 달력 리캡 마지막 쪽은 일기 몫이니 "여행 랭킹/어워드" 리캡(가장 많이 찍은 곳, 가장 오래 머문 곳, 가장 이른 사진 06:58 같은 카드 스택)으로 바꿔라. 큰 시각 숫자·214km 는 계속 너희 것.
- c 여행 수첩: 큰 17:40·19:05·214km 빼고 그 자리를 콜라주(겹친 아치·원·말풍선·지명 큰 글자 Gowun Dodum)로. 누끼(손 귤·조개·모자) 다각형이 거칠어 싸 보인다 — 점을 늘려 매끈하게 하거나, 손 대신 물체만(귤 하나, 조개 하나) 원형/둥근 실루엣으로 깔끔하게, 흰 외곽선 균일하게. 지도는 섬 실루엣 대신 **경로 카드형**(지도 앱 경로 화면 조각: 점-선-점 + 시간)으로 차별화해도 좋다.
- diary 일기: 달력 동그란 사진이 날짜 칸 아래로 밀려 있다 — 날짜 숫자와 같은 칸 안에 정확히(숫자 뒤/위 원형). 나머지 좋음.
- mag 잡지: 기본 색을 노랑 #F5D90A + 딥그린 #1F4D3A 로(코발트는 기록 카드 몫). 214km 초대형 2번(표지③·마지막) 빼고: 표지③는 다른 큰 글자(지명·"vol.01" 등), 마지막 쪽은 판권면(colophon: 발행일·사진 46·영상 3·9곳·214km 를 작은 표로) 같은 잡지다운 끝. 17:40·19:05 초대형 시각 → 지명 큰 글자로. "어디 갔냐면" → "어디 갔나"(~냐 말투 금지).
- album 앨범: 큰 시각 숫자(09:42·19:05·13:30) 빼고 프레임 번호·롤 정보·각인으로. 주황 전면 색면 쪽(표지③·19:05 쪽) 빼기 — 주황은 각인 전용. 표지③는 다른 아이디어(예: 필름 롤 3개 밀착 띠, 현상소 봉투 대신 "인덱스 프린트 한 장"이 표지 전체). 마지막 "46 컷"은 너희 장치니 유지.
