# CRIT-6 — 처음 보는 AD 한 명 (r5 시트 + pp-<key>-N 전 쪽)

근거: sheet 6장, b·c·diary·mag 의 pp-*-0~13 전 쪽(330×441), 각 html 의 CSS 변수.
대비는 CSS 색으로 계산(WCAG), 사진 위 글자는 렌더 픽셀로 확인. 쪽 표기 = pp-<key>-N (0~2 표지, 3~13 본문).

## 판정

| 테마 | 이름 걸겠나 | 한 줄 |
|---|---|---|
| b 기록 카드 | 아직 | 214·970·표지①은 통과. 회색 종이 통계 쪽 2장이 album 과 같은 책으로 보임 |
| c 여행 수첩 | 아직 | 본문 9쪽이 전부 같은 제목 블록(칩 + 32px), 표지②가 a·album 과 겹침 |
| diary 일기 | 아직 (한 쪽 차이) | 절제는 넷 중 가장 디자이너다움. pp-diary-10 이 고장으로 보임 |
| mag 잡지 | 예 | 유일하게 "누가 편집했다" 가 보임. 마지막 쪽만 a 와 분리하면 됨 |

## b

고칠 3가지
1. **pp-b-5** 밀착 인화 쪽 삭제. 92px 썸네일 8장 + 7px 틈 + 회색 종이 + mono 머리줄 = album p2·p6. → 풀블리드 1장 + 숫자 "13km" 26cqw 이상 + 하단 썸네일 4장 띠(높이 82px, 틈 2px).
2. **pp-b-9·pp-b-4** 종이 패널: 통계 아래 50px 가 죽음. pp-b-9 사진 y=220→300, 썸네일 틈 2px 한 띠, "아래 No.27 · 29 · 32" 삭제, 숫자는 7장 하나. pp-b-4 사진 290→330px, 통계 바닥 정렬.
3. 숫자 리듬: 중간 쪽 숫자가 10cqw(33px)로 소심. pp-b-7 "88km" 를 26~30cqw 로. pp-b-12 "5장" → "37분" 또는 삭제. 큰 숫자 쪽은 214·88·970 세 번.

깨진 것
- **데이터** pp-b-13 "가장 오래 머문 곳 · 월정리 1시간 15분" → 우도 09:42–11:21 = 1시간 39분이 더 김. (46개 시각·No.·2시간 57분·48시간 32분·62+88+64=214 는 맞음.)
- **대비** `.lb{opacity:.62}` 파란 면 위 3.5:1 (pp-b-13, 11.2px), `.hx s` 축 눈금 3.5:1 (pp-b-10, 9.9px). → .85 이상.
- pp-b-5 06.12 묶음에 도항선 난간(06.13 우도) 사진.
- mono 가 album 과 같은 JetBrains Mono.

## c

고칠 3가지
1. 제목 크기 두 단계. pp-c-4·6·8·9 와 pp-c-5·7·10·12 가 모두 칩 + 32px. 풀블리드 2장(pp-c-5, pp-c-10)은 56~64px. pp-c-9 는 아래 70px 가 비고 썸네일 90×88 이 떠 있음 → 150×150 재단 또는 삭제 + 사진 y=300.
2. 지도(pp-c-0, pp-c-3): 날 바뀜 점선 두 줄이 겹선 오류처럼 보임 → 날별 꺾은선 3개, 점선 삭제. 칩 규칙 통일(5px 점 + 1px 지시선 + 칩). pp-c-3 섬은 면(#EFE7D3)으로 채움.
3. 표지② pp-c-1: a②·album③ 과 같은 처방 → 왼쪽 110px 기둥을 주황 면 + 검정 목록.

깨진 것
- **대비** 주황 #E8553B 숫자가 크림 위 9.5px 에서 3.36:1 (pp-c-1, pp-c-3 범례). → #C63F26(≈4.7:1) 또는 잉크.
- pp-c-7 "PDF 에서는" 띄어쓰기 오류. 글 4줄이 가장 복잡한 사진 위에 쌓임 → PDF 줄을 맨 아래 "영상 0:03 · PDF에서는 사진 한 장으로" 한 줄로.
- 바닥 날짜줄이 pp-c-4·6·10·13 에만 있음. "다음 →" 거리는 pp-c-4(19km)에만 있음. 규칙 하나로.
- pp-c-11 지명이 100px 기둥에서 "원물/오름" 으로 갈림.
- pp-c-9 "유채는 덤" — 6월 데이터와 불일치.

## diary

고칠 3가지
1. **pp-diary-10**: L 위 290px 공백. 폰은 한 쪽씩 넘기므로 "사진 안 뜬 쪽". → 한라산 안개를 `.win.v`(x 120→330, y 0→290)에, pp-diary-11 은 나무 계단 사진으로.
2. **pp-diary-8** 영상: 해녀 머리가 위에서 잘림 → object-position 50% 15% 근처.
3. pp-diary-5·9 선반 사진 187×248(면적 32%) = 지시서가 금지한 "여백 속 작은 사진". → 217×290, 위로 재단. 표지①은 유지.

깨진 것
- 표지③ pp-diary-2 "돌담, 귤, 사흘." — 금지된 문어체. 50:50 배치도 블로그 썸네일. 빼도 됨.
- --sub #75676A 4.56:1 턱걸이, 10.5px·400 이라 렌더는 3.5~3.9. → #6A5C5F.
- pp-diary-13 "12일" 썸네일이 분홍 벤치(13일 월정리 사진).
- pp-diary-1 날짜 줄바꿈 "6월 / 12일부터".
- 달력 요일은 맞음(6월 1일 = 월).

## mag

고칠 3가지
1. **pp-mag-13** = a p10 과 같은 쪽: 제목 "간 곳", 문장 "귤 까먹다 비행기 시간 됐다", 날개 사진 전부 동일. → 제목·문장·사진 교체.
2. **pp-mag-12**: pp-mag-8 과 같은 "큰 1 + 90×68 ×3" 반복, 썸네일 작음, 원물오름 쪽에 08:30 어리목 계단이 시간 역순. → 2장 138×104.
3. 표지② pp-mag-1: 크림 + 검정 제목 = a②·album③·c②. → 제목을 초록 #2D6A4F, 사진은 오른쪽 재단.

깨진 것
- **데이터** pp-mag-13 색인 "어리목 10" → 9. 우도 6·월정리 6·하도 7 순서가 시간순 아님.
- **글·사진** pp-mag-10 "해 지니까 파래졌다." 인데 사진은 주황·회색. 제목을 사진에 맞춤(구조 유지).
- **대비** `.ix dt{opacity:.7}` 초록 위 3.6:1 (9.5px).

## 지킨 것 (전 테마 확인)

▶ 50px + "PDF에서는 사진 한 장으로" 있음(b pp-8, c pp-7, diary pp-8, mag pp-9). 본문 ≥11px, 캡션 ≥9.5px. `filter` 선언 없음. 한글 글꼴은 전부 산세리프(Wanted Sans / Paperlogy / LINE Seed KR / Gmarket Sans + Pretendard). 겹침·글자 잘림·줄 끝 고아 음절·본문 내 같은 사진 중복은 네 테마 모두 없음.
