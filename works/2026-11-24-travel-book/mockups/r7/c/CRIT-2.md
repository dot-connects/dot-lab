# c 여행 수첩 — 비평 2라운드 (새 비평가)

본 것: sheet-c, pp-c-0·3·5·7·8·10·13 원본 크기, DIRECTION·NOTES·CRIT-1, refs sheet1·3·4·5, 비교 sheet-a. (쪽 번호 = pp-c-N, R = refs7/c 번호)

## 0. 책 한 권으로 먼저
표지 → 지도 → 장소 9쪽 → 판권을 넘기면 **9쪽이 전부 같은 얼굴**이다: 위 60~65% 사진 + 아래 크림 상자 + 32 굵은 장소명. 모듈은 A·B·C 로 바뀌지만 축소판(sheet-c)에서는 "위 사진/아래 크림" 한 가지로만 읽힌다. B(풀블리드)도 크림 띠가 y287–440(쪽의 35%)을 먹어서 A 와 구별이 안 된다. 그래서 **책에 정점이 없다** — 스토리에 올릴 "이 한 장"을 고를 수 없다. sheet-a 는 13쪽 중 5쪽이 사진만으로 꽉 찬 쪽이고, c 는 0쪽이다. 1라운드 수정(띠 통일·탭 숫자·지시선)은 완성도는 올렸지만 이 문제는 그대로다.

## 1. 점수
- **프로 완성도 7** — 기준선·번호·폴리오는 깔끔. 깎인 곳: 표지 ① 동쪽 핀 지시선 부채꼴, 번호 상자와 날 탭이 같은 빨강 숫자 상자라 헷갈림, 판권 통계가 9px.
- **20대 "올리고 싶다" 6** — 캡처할 쪽이 표지 ③ 하나뿐. 본문은 "정리 잘 된 블로그 카드" 9장.
- **테마 개성 7.5** — 번호+지도는 c 것. 다만 기본 표지 ②는 여전히 album·a 와 같은 얼굴이고 사진 위 55%가 빈 하늘.

## 2. 과감한 변경 3 (이게 본론)

### ① 표지 = 색 바다 지도 포스터, 이걸 기본값으로 (R06·R36·R35)
R06 Herb Lester 는 바다가 주황 면이고 땅이 종이색, R36 Volkhonka 는 표지 전체가 노랑에 번호만, R35 Wildsam 은 단색 표지. 레퍼런스에서 "올릴 만한" 것은 전부 **색면 + 번호**다. 지금 표지 ①은 크림에 0.75px 회색 선이라 축소하면 빈 종이.
- 바탕 전면 `--acc`(토마토/코발트/숲 = 팔레트가 곧 표지 3색), 제주 섬은 `--paper` 채움(선 없음), 섬 폭 x−15–345, y150–340 (좌우 살짝 잘림).
- 핀은 먹 채움 18×18 + 종이색 숫자, 경로 1px 먹. 라벨(`01 협재 13:20`)은 on 색.
- 제목 XL 72 on 색, y20. 하단 y408 `2박 3일 · 9곳 · 214km`.
- 동쪽 03–06: 지시선을 섬 밖 오른쪽 위가 아니라 **섬 위쪽(y100–150)에 가로 한 줄**로 세우고 수직 지시선 4개(평행, 교차 0).
- "acc ≤5%" 규칙은 **본문 전용**으로 고친다. 표지는 예외 — 본문이 5%라서 표지 색면이 더 세게 먹힌다(R35 가 정확히 그 구조).
- 표지 ②는 버리거나, 남기려면 사진을 인물/갈매기 컷으로 바꾸고 x110–330, y120–440.

### ② B 모듈 = 진짜 풀블리드, 크림 띠 없음 (R10·R45·R46, R04)
R10 뮌헨 챕터·R46 Popeye 오프너·R04 Monocle 수영장 — 가이드북에도 사진만으로 꽉 찬 쪽이 반드시 있고 글은 사진 위에 얹는다. 지금 pp-5·7·10 은 띠가 153px 라 "풀블리드"가 아니다.
- 사진 330×440 전면. 글은 사진 위 왼쪽 아래: 번호 상자 18(acc 그대로) + 장소명 32/700 **흰색**, y 끝 384. 메타 C 흰색 85% y394. 메모 한 줄 B 흰색 y408. 폴리오 흰색 y420.
- 아래가 밝은 사진만 하단 160px 에 먹 0→40% 선형 그라디언트(그림자 금지 조항의 유일한 예외로 명시). 한라산·신창은 없이도 읽힌다.
- pp-7: 띠가 없어지면 해녀가 다 보인다. `.play` 는 y200.
- a 와 겹치지 않는 이유: a 는 얇은 거대 숫자, c 는 빨강 번호 상자 + 굵은 지명. 번호 상자가 사진 위에 찍히는 게 c 의 서명이 된다(R06 핀이 지도 위에 찍히는 것과 같은 문법).
- 결과: 9쪽 중 3쪽(날마다 1쪽)이 사진 쪽 → 리듬이 "카드·**사진**·카드·**사진**…" 으로 실제로 바뀐다.

### ③ 마지막 쪽 = 동선 정산표 한 장 (R25·R41·R20·R33)
R25 Belem 은 `1 BORDEAUX > BAYONNE … 4 jours – 710€` 를 색 숫자로, R41 은 일정을 선 하나에 꿰고 아래 `3000km`. 지금 pp-13 은 비행기 사진 + 9px 통계 한 줄이라 "끝"의 힘이 없고, 번호 체계가 마지막에 회수되지 않는다.
- 사진 없는 전면 타이포 쪽. 왼쪽 x38 에 1px 먹 세로선(y70–350), 선 위에 번호 상자 9개(간격 31px).
- 각 줄: `[01] 협재 해변` (Paperlogy 500·11.5) … 오른쪽 정렬 `13:20`(C). 줄 사이 선 옆에 acc 색 C `↓ 19km`. 날이 바뀌는 곳만 0.75px 괘선 + C `둘째 날 · 06.13 토`.
- 맨 아래 y360 굵은 1px 괘선 + **합계 줄만 L 32/700**: `214km` 왼쪽, 오른쪽에 C 3줄 `9곳 / 사진 46 / 영상 3`.
- y410 B "귤 한 봉지 사서 공항으로." — 유일한 문장.
- 바코드·절취선·찢긴 종이 금지(DIRECTION 5-7 유지). 영수증 "모양"이 아니라 표다.
- 비행기 사진(d8)은 pp-12 의 띠 한 칸으로 옮기거나 뺀다. pp-3 은 목록을 빼고 지도만 크게(①과 같은 그림의 종이색 버전), 목록은 이 쪽 하나로 — 같은 목록 두 번 문제도 같이 풀린다.

## 3. 쪽별 문제 (심각한 순)
1. **pp-1 (표지 ②, 현 기본값)** — 사진 위 절반이 빈 하늘, 제목과 목록 사이 y115–275 빈 칸, `01—09` 상자가 y70 오른쪽에 혼자 뜸. 세 표지 중 가장 약한데 기본값. → 기본값을 ①(색 바다)로. 
2. **pp-5·7·10 (B)** — 띠 153px, 2줄 장소명이면 띠가 쪽의 35%. → 변경 ②.
3. **pp-0·3 지도** — 03–06 지시선이 한 점으로 모이는 부채꼴 + 오른쪽 끝 수직선 4개가 회로도처럼 보임. 표지 ①은 y300–400 이 통째로 빔(섬이 쪽 높이의 30%). `신창 17:40` 만 핀 아래에 붙어 라벨 규칙이 깨짐. → 변경 ① 배치, 라벨은 전부 핀 오른쪽(왼쪽 가장자리 핀만 아래 허용이면 01·02 둘 다 같은 규칙으로).
4. **날 탭 (pp-4~12)** — 빨강 12px 상자에 `1`, 바로 옆에 빨강 18px 상자에 `02`. 같은 색 숫자 상자 두 개라 "어느 게 번호?"가 된다. 폴리오에 이미 `첫째 날 · 06.12 금`. → 탭 삭제. 번호 상자만 빨강.
5. **pp-13** — 오른쪽 아래 비네팅 모서리가 아직 보임(x300–330, y225–262). 통계 9px. → 변경 ③로 교체.
6. **pp-3** — 표지 ①과 같은 그림이 바로 다음 쪽에 반복. 목록 3단이 2/4/3줄로 기울고 y370–405 빔, 폴리오 `06.12-06.14` 가 부제와 중복. → 지도만 y60–400 으로 크게, 핀 옆에 쪽번호(`→ 02`) C 로.
7. **메모(B 11.5)** — "모자가 두 번 날아감" 같은 문장이 이 책의 유일한 내 목소리인데 메타와 같은 무게로 묻힌다. → 메모 먹 100%·Paperlogy 500, 메타는 soft 유지. 크기는 그대로(중간 크기 금지 유지).
8. **pp-12** — 메타가 `13:30` 뿐이라 줄이 비어 보임. → 읍면리 없으면 `13:30 · 셋째 날 마지막` 처럼 채우지 말고 메타 줄을 장소명과 같은 줄 오른쪽 끝으로 올려 한 줄 줄인다.
9. **pp-2 (표지 ③)** — 가장 좋음. 띠 아래 여백만 8 → 14px, 띠 y246–334.

## 5. 아직 없는 한 방
**색 바다 표지(변경 ①).** 피드에서 엄지 크기로 봐도 "토마토색 바다에 떠 있는 종이색 제주 + 번호 9개"는 한눈에 c 다. 팔레트 3색이 곧 표지 3종이 되어 고르는 재미도 생긴다. 사진 없이 성립하는 유일한 표지라 a·album·mag 어느 것과도 겹치지 않는다.
