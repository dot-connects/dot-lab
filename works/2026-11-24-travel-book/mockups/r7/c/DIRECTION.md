# c 여행 수첩 — 7차 방향 (330×440 설계 px, R=refs7/c 번호)

콘셉트: **"내가 다녀온 9곳의 안내서 — 번호 하나가 지도·목록·장소 쪽을 꿴다."**

## 1. 토론 (AD / 북 / 인스타 → 결론)
1. **콘셉트** AD 번호 체계가 곧 브랜드(R36·37) / 북 Monocle식 장소 모듈 반복(R09·29) / 인 "가이드북은 남의 책, 내 여행 같아야" → 번호+모듈, 글은 내 메모 한 줄. AD 승(책을 꿰는 건 번호뿐), 인의 "내 말투" 수용.
2. **버릴 것** AD 토마토 전면 / 북 아치·원·알약·폰 프레임·둥근 카드 / 인 96px 고딕 한 단어("포스터지 수첩 아님") → 전부 버림. 북 승(R 전체에 직사각 사진·괘선뿐). 큰 얇은 숫자 챕터(R10·39)도 버림 — a 테마 것.
3. **글꼴** AD Paperlogy 300 크게 / 북 700·32px 장소명+DM Mono 메타(R09) / 인 "얇으면 a랑 똑같음, 굵은 게 귀여움" → 700/32. 북 승, 800·64는 폐기. Instrument Sans 삭제(숫자는 모노 하나).
4. **그리드** AD 4단 / 북 기존 6단 유지+세로 기준선 고정 / 인 "여백 많으면 도록" → 6단, 사진은 바깥 가장자리로 블리드, 글은 y278 한 줄에서 시작. 북 승, 인 의견으로 여백 속 사진 금지.
5. **색** AD 먹+1색 5%(R28·30) / 북 가장자리 탭(R11·13) / 인 "색면 한 쪽은 있어야 올림" → 본문은 번호 상자·핀·탭만(≤5%), 색 전면은 없음. AD 승. 인 요구는 표지 ③ 사진 블리드로 대신.
6. **사진 배치** AD 장소당 1장 / 북 큰1+작은n 위계(R11, 같은 크기 나열 금지) / 인 "사진 많이 넣고 싶음, 풀블리드 꼭" → 장수로 모듈 3종 자동 선택(B 1장·A 2장·C 3~4장). 북 승, B(풀블리드)는 인 몫.
7. **표지** AD 번호 지도(R36) / 북 사진 1+지명 목록(R27) / 인 "사진 없는 표지는 안 고름" → 셋 다 후보, 기본값은 ②. 인 승(고르는 사람이 20대).
8. **시퀀스** AD 날마다 색면 오프너 / 북 오프너 없이 탭+러닝헤드, 모듈 교차 / 인 "같은 쪽 9번은 지루" → 오프너 없음, 같은 모듈 연속 금지(M C B A B C A B A C K). 북 승.
9. **지도** AD 제주 윤곽 선화(R32) / 북 "다른 여행은 윤곽 데이터 없음" — GPS 점+경로선만(R41) / 인 "핀 번호가 쪽이랑 같으면 재밌음" → 윤곽 있으면 0.75px 선, 없으면 점+선만으로 성립. 북 승.

## 2. 디자인 시스템
- **그리드** M 20 · 6단×40 · G 10 (단 c 시작 x=20+50(c−1)). 세로선 3개: 사진 바닥 y262 / 글 시작 y278 / 폴리오 y420.
- **글꼴** kfonts `Paperlogy:400;500;700`, fonts `DM+Mono:wght@500`.

| 단 | 용도 | 값 |
|---|---|---|
| XL | 표지 제목만 | Paperlogy 700 · 72 · −.05em · 1.0 |
| L | 장소명 | 700 · 32 · −.04em · 1.12, 최대 2줄, balance |
| B | 메모·목록 | 400 · 11.5 · −.015em · 1.6 (목록 장소명은 500) |
| C | 메타·폴리오·번호 | DM Mono 500 · 9 · +.02em · 1.4, tabular |

 한 쪽에 3단까지. 장소명 최대 32 — XL은 본문에 없음.
- **색** `--paper #FBF6EA` `--ink #151515` `--soft #6B665C` `--line #D9D2C2`(0.75px 괘선) `--acc #E8553B` `--on #151515`(acc 위 숫자).
 팔레트 3: 토마토 #E8553B/on 먹 · 코발트 #2F5FD0/on 흰 · 숲 #1F6B4A/on 흰. 종이·먹은 고정. acc 면적 쪽당 ≤5%.
- **번호 상자** 18×18 직각, acc 채움+on 숫자(C). 목록·지나온 곳은 먹 1px 테두리만. 지도 핀은 14×14 같은 상자.
- **날 탭** 오른쪽 가장자리 6×44 acc. 1일 y20 / 2일 y74 / 3일 y128. 지도·판권 쪽 제외.
- **사진 틀**(직사각만, 간격 G, filter 없음): 풀블리드 3:4 / 히어로 330×262(5:4) / 큰 세로 210×262(4:5) / 작은 칸 110폭(높이 126·80.7) / 정사각 90.
- **모듈 자동 선택**(장소 사진 n장):
 - **B** n=1 — 풀블리드, 왼쪽 아래 종이 라벨(x0–210, y330–440)에 번호·장소명·메타. 하단이 밝아 쪽번호가 안 읽히면 라벨 전폭.
 - **A** n=2 — 히어로(위·좌·우 블리드, y0–262) + 글 영역 5–6단에 정사각 90(y278–368).
 - **C** n=3~4 — 큰 세로(위·좌 블리드 x0–210) + 오른쪽 띠(x220–330, 우 블리드) 2칸 또는 3칸.
 - n≥5 — 4장씩 C로 끊고 나머지는 위 규칙. 이어지는 쪽은 장소명 대신 C단 "05 월정리 — 이어서", 메모 없음.
 - 대표 컷 = 가로면 A 히어로, 세로면 B/C 큰 세로. `object-position` 은 피사체 3분할.
- **장소 글 블록**(y278부터, 1–4단; C·B는 폭에 맞춤): 번호 상자 + L 장소명 → C 메타 `13:20 · 한림읍 협재리 · 맑음 24°`(시각→읍면리→날씨, 없는 값은 건너뜀) → B 메모 ≤2줄 → 괘선 + C `다음 → 02 신창 풍차해안도로 · 19km`.
- **사진 캡션 없음** — 메타 줄이 캡션. 날의 첫 장소는 메타 위에 C `첫째 날 · 06.12 금`.
- **폴리오** y420: 왼쪽 C `제주 · 첫째 날`, 오른쪽 쪽번호 2자리. 사진 위면 흰색.
- **지도** 윤곽 0.75px soft, 경로 1px ink 실선(방문 순), 핀=번호 상자. 핀 간격 <16px면 한쪽을 밀고 0.75px 지시선(R06). 그림자·질감·아이콘 없음.

## 5. 하지 마
1. 아치·원형·기울임·둥근 모서리·그림자·흰 테두리 — 사진은 직사각뿐(`.play` 버튼만 예외).
2. 알약·말풍선·둥근 카드·폰 프레임·재생바 — 구획은 0.75px 괘선과 여백으로.
3. acc 전면 색면, 쪽당 acc 5% 초과 — 번호 상자·핀·날 탭에만.
4. 본문에 32px 넘는 글자, 얇은 거대 숫자(a 것), 큰 시각 숫자(b 것).
5. 쪽마다 다른 틀 — 본문은 M·A·B·C·K 다섯 가지뿐, 글은 항상 y278에서.
6. 같은 크기 사진 나열·3×N 밀착 그리드(album 것), 여백 한가운데 뜬 작은 사진.
7. 손글씨·마스킹테이프·크래프트 질감·나침반·비행기 점선·가짜 티켓 — 실물 사진이 없으면 안 만든다.
8. 번호 불일치 — 지도 핀·목록·장소 쪽 번호와 순서가 하나라도 어긋나면 책이 무너진다. 사진별 캡션·중간 크기 글자도 추가 금지.
