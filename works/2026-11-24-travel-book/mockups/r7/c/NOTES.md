# 여행 수첩 (c) — 원형 노트

원형 = **"쓸모 있는 안내서"**. 감성 포토북이 아니라 실제로 쓰는 가이드북·지도·수첩. 사진은 증거이고, 정보 체계(번호·주소·시간·지도)가 주인공.

## 1. 프로답게 만드는 것 (11)
1. **번호 체계 하나가 책 전체를 꿴다.** 장소 = 번호, 지도 핀·목록·본문이 같은 번호 (06, 20, 36, 37, 44). 우리: 장소 1~9 번호를 경로·지도·쪽 머리에 똑같이.
2. **포인트 색 1개 + 먹 1개.** 오렌지만(28·29·30), 빨강만(14·15), 세피아 1색(19·20). 면적은 5% 이하 — 핀·라벨·숫자에만. 바탕 크림/흰 + 먹.
3. **글자 위계는 3단, 크기 대비가 극단.** 장소명 28~40pt : 본문 8~9pt : 메타(주소·시간) 6~7pt 대문자/모노, 대략 5:1:0.8 (09, 11, 03). 중간 크기가 없다.
4. **여백이 크다.** 바깥 여백 = 판형 짧은 변의 8~12%, 하단 여백이 더 넓음 (09, 17, 32). 텍스트 블록은 쪽 폭의 40~55%만.
5. **장소 페이지는 모듈이다.** 사진 1~3 + 장소명 + 주소 한 줄(핀 아이콘) + 2~4줄 글 + 정보 줄(시간·가격·별점) — 모든 장소가 같은 틀 (09, 11, 02, 29).
6. **사진은 크기 위계가 분명.** 큰 것 1 + 작은 것 1~2, 비율 약 3:1 (11, 03). 같은 크기 사진 나열 금지.
7. **챕터 구분 쪽이 리듬을 만든다.** 거대한 숫자(얇은 세리프/산세리프, 쪽 높이 30~50%) + 섹션명 한 단어 (10, 38, 39, 47).
8. **지도는 단색 선화.** 회색/세피아 극세선, 강조는 포인트 색 핀만 (30, 32, 44, 12). 위성·컬러 지도 아님.
9. **러닝헤드·탭.** 세로 쪽 머리(도시명·섹션) 6pt, 가장자리 색 탭 (11, 13). 책이 "찾아보는 물건"임을 보여줌.
10. **종이 질감이 정보다.** 크래프트·판지·크림 + 단색 인쇄 (21, 31, 48). 그라디언트·그림자 없음.
11. **수첩 쪽은 '붙인 실물'.** 티켓·영수증·라벨을 그리드 종이에 직선으로, 손글씨는 한 줄 (50~54).

## 2. 페이지 패턴 10 → 3:4 한 쪽으로
1. **장소 모듈 (09)** — 위 55% 사진 1장, 아래 장소명 32pt + 주소/시간 한 줄 + 글 3줄 + 하단 정보 줄.
2. **챕터 숫자 (10, 39)** — 풀블리드 사진, 오른쪽 아래 얇은 거대 숫자 "2"(쪽 높이 40%) + "둘째 날".
3. **경로 리스트 (25)** — 번호 · A → B · 이탤릭 한 줄 · 포인트색 시간/거리. 하루 하나씩 표처럼.
4. **번호 지도 + 목록 (37, 44)** — 위 60% 단색 선화 지도에 번호 핀, 아래 번호 목록 2단 + 쪽 참조.
5. **날짜 깃발 타임라인 (41)** — 흰 바탕 지도 윤곽 위 세로선 + 날짜·지명 라벨, 하단 "214km".
6. **사진 위계 3장 (11)** — 큰 1 + 작은 2, 드롭캡 본문, 세로 러닝헤드.
7. **목차 (45)** — 풀블리드 하늘 사진 위 작은 흰 글자 2단 목차(장소·쪽번호).
8. **극단 여백 한 장 (17)** — 사진 하나 쪽 폭 50%, 장소명만, 나머지 비움.
9. **실물 붙이기 (50, 51)** — 모눈 크림 바탕에 티켓/영수증 사진을 직각으로 + 날짜 스탬프 + 손글씨 한 줄.
10. **인덱스 (33, 44)** — 끝 쪽: 번호 박스 + 가는 괘선, 장소·시간·쪽.

## 3. 6차 시안(sheet-c)이 아마추어 같은 이유
1. **수첩이 아니라 포스터다.** 01·03·07·11 모두 초대형 고딕 한 단어 + 빨강 면. 가이드북의 정보 체계(번호·주소·지도)가 2쪽(경로 표) 말고는 없다.
2. **빨강 면적이 너무 크다.** 표지·03·05·07·11에 쪽의 50~100%. 레퍼런스는 포인트색 5% 이하.
3. **위계에 중간이 없고 메타가 약하다.** 장소명은 거대한데 주소·시간 메타가 체계 없이 흩어짐(02 "13:20·협재 해변", 04 우측 흩어진 문장). 정보 줄 틀이 쪽마다 다름.
4. **UI 부품이 책을 깬다.** 경로 카드 둥근 모서리(01 경로표, 03 협재→신창 칩), 05 폰 프레임+재생바, 04·07 알약 버튼 — 앱 화면이지 인쇄물이 아니다.
5. **아치 마스크·원형 크롭(표지, 10, 11)** — 템플릿 장식. 레퍼런스는 직사각형 사진만, 장식은 번호·선.
(+ 지도가 없다: '여행 수첩'인데 동선을 그림으로 보여주는 쪽이 0.)

## 4. 표지 아이디어 5
1. **번호 지도 표지 (36)** — 크림 판지 바탕에 제주 윤곽 극세선 + 장소 번호 1~9를 실제 위치에, 아래 "제주 6.12–6.14".
2. **단색 + 원 라벨 (34, 35)** — 한 색(귤색) 전면 + 가운데 크림 원 라벨 "JEJU / 여행 수첩 / 2026.06".
3. **숫자 반복 (14)** — 날짜 "0612 0613 0614" 를 면 가득 반복, 한 곳만 포인트색.
4. **사진 한 장 + 지명 목록 (27)** — 흰 표지, 가운데 사진 하나(쪽 폭 60%), 위에 "제주" + 작게 장소 9곳 나열.
5. **크래프트 수첩 (48)** — 크래프트 질감 + 가로 띠 라벨에 타자체 "제주 · 2박 3일 · 46장".

## 5. "아재/AI 템플릿" 함정 5
1. **손글씨 폰트 남발·스티커·마스킹테이프 그래픽** — 진짜 수첩(50~54)은 실물 사진이지 가짜 데코가 아니다.
2. **오래된 양피지·나침반·비행기 점선 아이콘** — "여행" 클리셰. 지도는 단색 선화와 번호면 충분.
3. **쪽마다 다른 레이아웃** — 프로는 같은 모듈 반복으로 신뢰를 만든다(29, 02).
4. **둥근 카드·칩·그림자** — 앱 UI 문법. 인쇄물은 괘선·여백으로 구획.
5. **모든 쪽에 큰 제목** — 큰 글자는 챕터 쪽에만; 장소 쪽은 28~40pt 장소명 + 작은 메타.
