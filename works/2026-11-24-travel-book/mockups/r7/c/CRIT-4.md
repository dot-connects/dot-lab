# c 여행 수첩 — 비평 4라운드 (마감 점검, 새 비평가)

본 것: sheet-c + pp-c-0~13 전부 원본, 문제 쪽은 3배 확대, 대비는 픽셀로 측정. 쪽 번호 = pp-c-N.

## 1. 점수
- **프로 완성도 8** — 기준선(괘선 y385, 폴리오 y412–420)은 전 쪽에서 1px 안으로 맞는다. 깎인 곳: 사진 위 글자 대비 2곳, 지도 지시선, pp-11 혼자 다른 틀.
- **20대 "올리고 싶다" 7.5** — 토마토 표지(pp-0)·정산표(pp-13)·한라산(pp-10) 세 장은 캡처감. 하도·신창은 글자가 사진에 묻혀서 탈락.
- **테마 개성 8.5** — 번호 상자 + 색 바다 지도 + 정산표는 다른 테마에 없다.

## 2. 수정 (심각한 순, 10개)

1. **pp-7 하도(영상)** — "하도"가 민트색 의자 위(배경 중앙값 대비 4.1:1, 밝은 곳은 2:1 이하), 메타 9.5px 두 줄이 모래 위. 스크림이 y280에서 알파 0으로 시작해서 제목 자리엔 거의 안 걸린다. 게다가 글이 5줄(제목 2·메타 2·메모 1).
   → `.grad::after` 높이 160 → 220, `linear-gradient(transparent, rgba(21,21,21,.5) 35%, rgba(21,21,21,.72))`. `PDF 에서는 사진 한 장으로` 줄 삭제(책 안에 들어갈 문장이 아니라 앱 안내 — 시안 밑 설명줄로). 그러면 4줄, 제목이 대야 아래로 내려온다.
2. **pp-5 신창** — "풍차해안도로"의 "도로"가 밝은 수면 위: 대비 2.2:1. → 1번 스크림 공통 적용이면 약 6:1. 추가로 `object-position` y를 5% 올려 수면 하이라이트를 y300 위로.
3. **pp-3 지도 지시선** — 동쪽 4개가 꺾은선으로 x278–300 에 3px 간격 세로선 3줄 + 순서가 05·04·06·03 이라 회로도. 표지(pp-0)는 같은 점을 직선 수직(05·04·03 위, 06 아래)으로 깔끔하게 풀었는데 두 쪽이 서로 다른 그림.
   → pp-3 도 pp-0 배치 그대로(직선 수직, 꺾임 0). `N쪽` 라벨은 상자 오른쪽이 아니라 위 4개는 상자 위(y−12), 06 은 상자 아래.
4. **pp-3 `N쪽` 라벨 충돌** — `03쪽`·`08쪽`·`09쪽` 세 개가 점선 경로 위에 걸쳐 있다. 그리고 핀 `01` 옆 `02쪽` 은 번호 체계가 두 개로 읽힌다.
   → 서쪽 라벨은 경로선 반대쪽으로(02→상자 아래, 07→상자 위, 08→상자 아래), 색은 soft 유지 + 앞에 `p.` 대신 지금처럼 `쪽`, 단 크기 8.5 로 한 단 낮춤. 여유 없으면 라벨 전부 빼고 y395 에 C 한 줄 `번호 + 1 = 쪽`.
5. **pp-11 원물오름** — 이 쪽만 글이 위(y20)에서 시작, 메모(y123)와 작은 사진(y263) 사이 127px 가 빈다. 사진 시작 x145 는 6단 그리드 어디에도 없는 선. 메타가 두 줄(`11:10` / `안덕면 동광리`)로 쪼개져 다른 쪽의 `· ` 한 줄 형식과 다르고, `다음 → 09` 는 지명이 빠졌다.
   → 큰 사진 x120–330(4단+블리드), 글 기둥 x20–110. 작은 사진을 위로(x20–110, y20–110 정사각 90), 번호 상자·제목은 다른 쪽과 같은 y278 에서 시작. 메타 한 줄 `11:10 · 동광리`, 다음 줄 `→ 09 귤나무 카페`.
6. **pp-13·pp-0 토마토 위 작은 글자** — #151515 on #E8553B = 4.3:1, 9.5px 메타(날 머리글·시각·오른쪽 통계·폴리오·표지 날짜)가 기준 미달.
   → acc 바탕 쪽은 글자색 `#000`(5.0:1) + 메타 10px. 번호 상자 안 숫자도 같은 값(`--on:#000`).
7. **메타·폴리오 한 줄 안 두 가지 굵기** — `11:10`(DM Mono 500, 진함) 옆 `안덕면 동광리`(Paperlogy, 얇고 연함), `셋째 날 · 06.14 일` 도 한글만 가늘다. 캡션 스타일이 두 개로 보인다.
   → `.k` 에 `font-weight:500` + 색 상속 명시, Paperlogy 500 로드 확인. 자간 −.01em → 0.
8. **pp-12 귤나무 카페** — 시각 `13:30` 만 제목 줄 오른쪽 끝에 있고 다른 8쪽은 제목 아래. y335–385 50px 빈 칸. → 제목 아래 메타 줄 자리로 되돌림(값이 짧아도 자리는 고정). 실제 데이터에서 읍면리 없는 장소가 흔할 테니 "짧은 메타도 같은 자리"가 규칙이어야 한다.
9. **pp-6·pp-9 정사각 사진 윗변** — 사진 y279, 번호 상자·제목 y282–283. 3–4px 어긋남이 바로 옆이라 보인다. → 사진 top 을 상자 top(y282)에 맞춤, 높이 86 또는 아래로 3px.
10. **pp-1 표지 ②** — 왼쪽 기둥 y125–275 가 150px 빈 칸, 목록은 바닥에 몰림. 사진 맨 아래 가운데(x165–200) 잘린 머리 하나. → 목록을 사진 윗변 y122 에 맞춰 위로, `object-position` y 를 올려 머리를 프레임 밖으로. (기본값이 pp-0 이면 우선순위 최하.)

잔손질(한 줄씩): 날짜 구간은 하이픈 말고 en dash(`06.12–06.14`, pp-0·1·3) / pp-13 통계 `9곳·사진 46·영상 3` → `장소 9 / 사진 46 / 영상 3` 로 형식 통일 / 본문 11.5 는 띄어쓰기가 좁다 — `word-spacing:.08em`.

## 3. 버릴 것 / 지킬 것
**버릴 것** 1) 책 안의 `PDF 에서는…` 안내 줄 2) pp-3 꺾은 지시선 3) pp-11 의 "글 위에서 시작" 예외.
**지킬 것** 1) 토마토 표지 + 정산표(책의 앞뒤가 같은 색으로 닫힘) 2) y385 괘선·y412 폴리오 3) 풀블리드 위 빨강 번호 상자 + 흰 굵은 지명(pp-10 이 기준 — 이 정도로 읽혀야 한다).

## 4. 아직 없는 한 방
지도에 **지명이 없다** — 번호만 9개라 pp-3 을 캡처해도 어디인지 모른다. 동쪽 4개는 자리가 없으니 pp-3 하단 빈 칸(y345–400)에 C 3열×3줄 `01 협재 · 02 신창 …` 한 벌만 얹으면 지도 한 장이 혼자서도 성립한다(R37·R44).
