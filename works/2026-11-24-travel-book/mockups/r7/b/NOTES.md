# 기록 카드(b) — 원형 노트 (refs7)

## 1. 프로답게 만드는 것
1. **숫자 하나만 크게**: 큰 숫자 : 라벨 = 10~15 : 1. 한 쪽에 초대형 숫자는 1개, 나머지는 중간 크기 3~6개 (04, 09, 16, 19).
2. **색 1개 + 중성색**: 바탕 1색(회색·하늘·흰색) + 강조색 1개. 강조색은 면적 5% 미만, 숫자·경로선에만 (05, 06, 08).
3. **라벨-값 짝**: 모든 숫자 위에 대문자 6~7pt 라벨, 아래에 단위·설명 한 줄. 라벨 없이 숫자만 두지 않는다 (03, 29, 30, 39).
4. **괘선 그리드**: 0.25~0.5pt 선으로 칸을 나누고 4단(또는 2단) 그리드를 지킨다. 박스·둥근 카드·그림자는 없다 (01, 05, 42, 35).
5. **글꼴 2개**: 콘덴스드/세리프 숫자 1종 + 작은 산세리프/모노 1종. 크기는 3단계뿐 (04 vs 02 세리프).
6. **사진은 기록물처럼**: 원형·작은 정사각 썸네일, 같은 크기·같은 각도로 반복 (01, 41, 28). 큰 사진은 숫자 없는 '쉬는 쪽' 하나로 따로 (15, 34).
7. **지도는 선 1색**: 배경 지도는 가는 선, 경로는 강조색 선 1줄 + 점. 섬 윤곽을 둥글게 그린 만화체는 쓰지 않는다 (06, 09, 33, 36).
8. **여백**: 바깥 여백 6~8%, 정보는 위나 아래 한쪽에 몰고 30~40%를 비운다 (31, 40, 33).
9. **목차·색인**: 페이지 번호 + 항목 + 색 띠가 '체계'를 보여 준다 (10, 11, 38, 42).
10. **실물 서식 질감**: 칸·구멍·도장·바코드 같은 서식 요소 하나가 '기록'이라는 말을 대신한다 (23, 27, 22, 29).
11. **같은 틀 반복**: 분기·일차마다 레이아웃이 같고 값만 바뀐다 (01·02, 13·14).

## 2. 페이지 패턴 10 → 폰 세로 3:4 한 쪽
1. 초대형 숫자 1 (04): 위 2/3에 '214', 아래 라벨 3줄. 사진 없음.
2. 색 띠 통계 (12): 가로 띠 4줄, 각 줄 오른쪽 끝에 숫자 하나.
3. 지도+점+작은 사진 (01): 선 지도 위 방문지 점, 점마다 원형 썸네일 지름 12%.
4. 라벨-값 표 (30): 2단 표 '날짜/시각/장소/날씨'를 위에, 사진 1장 아래 50%.
5. 유형학 그리드 (41): 같은 비율 사진 3×3, 아래에 번호 + 시각 캡션.
6. 쉬는 쪽 (15, 34): 풀블리드 사진 하나, 구석 6pt 좌표만.
7. 목차/색인 (11): 일차 줄마다 '쪽번호·장소·장수'를 색 띠로.
8. 로그 서식 (39): 칸 있는 빈 서식처럼 그리고 값을 채운다(번호/시각/km/장소).
9. 티켓 (29): 위 70%는 사진, 아래 30%는 티켓처럼 큰 값 3개 '06.13 09:42 우도'.
10. 결산 (03): 2단 × 4줄 '큰 숫자 + 라벨 + 작은 아이콘', 박스 없이 괘선만.

## 3. 6차 시안(sheet-b)이 아마추어처럼 보이는 이유
1. **색이 4개 (파랑·라임·분홍·검정)가 쪽마다 바뀐다** — 레퍼런스는 책 전체에 1색 + 중성색 (05, 08). 01·03·09쪽이 서로 다른 책처럼 보인다.
2. **큰 숫자가 '시각'뿐이라 데이터가 없다** — 13:20, 09:42, 08:30, 0:03이 반복돼 숫자가 정보를 주지 못한다. Feltron은 숫자마다 단위·비교 대상이 있다 (02, 04).
3. **라벨이 없다/약하다** — '214km', '3일 9곳'이 라벨-값 짝 없이 떠 있다. 03쪽 색 블록(3/9/46/3)은 앱 위젯 같다 (12와 비교).
4. **지도가 만화처럼 둥글다** (02·03쪽 제주 윤곽 + 핑크 점) — 레퍼런스 지도는 가는 선 + 경로 1줄 (06, 36).
5. **둥근 알약 칩·흰 카드·그림자** (01쪽 경로 칩, 02쪽 우도 카드, 11쪽 '1등' 리스트) — 기록물이 아니라 앱 UI 문법이다. 괘선 표로 바꾼다 (42, 30).

## 4. 표지 아이디어

2. 별자리 (33): 짙은 1색에 방문지 46장의 GPS 점만 찍고, 아래 작게 '제주 2026'.

4. 색인 패턴 (38): 촬영 시각 46개를 작은 글자로 빽빽이 깔고 '제주'만 크게.
5. 목록카드 (27): 크림색 카드에 청구기호처럼 '2026.06 · 제주 · 46'.

## 5. 함정 (아재/AI 템플릿처럼 보이는 것)
1. 인포그래픽 아이콘(비행기·카메라·발자국)을 숫자 옆에 붙이기 — 클립아트가 된다.
2. 숫자마다 다른 색 블록 — 대시보드/앱 위젯처럼 보인다 (현 03쪽).
3. 가짜 바코드·QR·여권 도장 남발 — 서식 요소는 책 전체에 하나만.
4. '1등', '최고의 순간' 같은 랭킹 문구 — 수치가 아니라 의견이다. 숫자는 사실만.
5. 둥근 모서리 카드 + 그림자 + 큰 이모지 — 기록물이 아니라 SNS 템플릿.
