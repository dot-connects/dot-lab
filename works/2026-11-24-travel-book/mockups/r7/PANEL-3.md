## b — 고칠 것 3

1. **p07 격자를 없앤다.** p03 과 같은 3×3 격자가 두 번, album 밀착인화와도 겹침. p07 = 큰 사진 1장(높이 55%) + 아래 3장 띠 + 숫자 2개. 격자는 p03 한 번만.
2. **p08 타임라인을 파란 바탕 주인공으로.** 지금 막대 높이 ~26px 로 사진 밑 부록. 사진 45%로 줄이고 날짜 행 높이 56px, 바탕 파랑·막대 흰색. 파랑이 p01·p11 에만 있어 중간이 밋밋한 것도 같이 풀림.
3. **하단 눈금자 정리.** 11쪽 전부에 있음. 전면 사진쪽(p04·p06·p09)에서는 빼고, p06 은 사진 위 3줄(PDF 문구·▶0:03·눈금) → 2줄. p10 은 캡션과 눈금 간격 12px 이상. № 캡션 9.5px 이상 실측.

메모: p03 의 모자(14:02)·귤(14:15)이 첫날 협재로 들어가 있음 — 다른 테마에선 우도·귤나무 카페. 목 데이터 통일.

## c — 고칠 것 3

1. **p01·표지① 지도.** 03~06 지시선 4개가 동쪽 끝 한 점에 모이고 섬이 덩어리 모양. 점은 실제 좌표로(서로 14px 이상), 번호칩은 점 바로 옆, 지시선 최대 24px. 섬 외곽은 실제 제주 윤곽 단순화. "0N쪽" 은 칩 옆 한 번만.
2. **p05 영상쪽에 "PDF 에서는 사진 한 장으로" 가 없다(필수).** 메타 줄 아래 9.5px. 전면쪽(p03·p05·p08) 흰 제목은 글자 그림자 대신 아래 40% 스크림(검정 0→45%).
3. **같은 실루엣 6쪽(02·04·06·07·09·10: 사진 위 58% + 제목 아래).** p06 은 제목 블록을 위 30%로 뒤집고, p09 는 세로 사진 오른쪽 62% + 글 왼쪽 38%. c 만의 장치인 "다음 → 0N" 을 11px→13px 로 키우고 모든 쪽에 km(p02 에만 있음, GPS 로 계산 가능).

## diary — 고칠 것 3

1. **p03·p07 작은 사진쪽.** 사진 폭 27%·42%, 위 40% 가 빈칸 — 로딩 실패처럼 보임. 작은 사진쪽은 p07(의자) 하나만 남기고, p03 은 사진 폭 55% 이상·위 여백 12%.
2. **글이 1~2줄뿐이라 7쪽에서 아래 30% 가 죽는다.** 날짜쪽(p1·p4·p8)은 본문 5~7줄(12px, 행간 1.75) 허용. p8 글만 있는 쪽은 6줄을 중앙에 — 지금은 한 줄이라 빈 쪽으로 읽힘. 나머지는 사진 영역 66%→72%.
3. **p6 영상쪽에 "PDF 에서는 사진 한 장으로" 가 없다(필수)** — "영상, 3초." 뒤에 붙임. ▶ 50px 실측. p5·p9 전면 사진은 재단 대신 종이 여백 20px 액자로(아래 충돌 참고).

메모: p11 달력(여행 3일만 사진)은 이 테마 최고 장치. 칸 30px→40px.

1. **Part 표지 3장(p2·p5·p9)이 a 의 날짜 표지와 같은 구조·같은 사진.** p5(Part 2)를 녹색 바탕 + 사진 인셋(폭 70%)으로. 녹색이 p1·p11 에만 있는 것도 풀림. p2·p9 는 전면 유지.

## 테마 간 충돌

| 겹치는 것 | 어디 | 양보 |
|---|---|---|
| 크림 바탕 + 검정 굵은 "제주" + 사진 표지 | a② c② mag② album③ | 넷 다 기본 표지에서 제외 |
| 갈매기 사진 표지 | a① b② c② album① | a 만 기본으로 |
| 유채 사진 표지 | diary② mag① | diary 양보(①) |
| 날짜/Part 전면 표지 3장 | a p1·4·8 ↔ mag p2·5·9 | mag (fix 1) |
| 안개 봉우리 전면, 8~9쪽 | 6개 전부 | diary 는 액자, b 는 970m 로 이미 구별 |
| 격자 + 모노 프레임 번호 | b p03·07 ↔ album | b (격자 1번만) |
| 사진 위·캡션 아래 + 크림 종이 | c ↔ a·album | c (fix 3). p11 일정표를 주황 바탕으로 |
| 색 바탕 첫 쪽 + 색 바탕 끝 쪽 | b 파랑 ↔ mag 녹색 | 내용이 달라 허용. c 는 p01 을 크림으로 유지 |

종이색: a·c·mag·album 넷이 따뜻한 크림. 구별은 강조색 면적으로 — c 주황이 칩(12px)뿐이라 제일 약함. 칩 20px.
