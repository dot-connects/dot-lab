가장자리 경우

경우이렇게 돼요
그룹 사람이 대는 중에 주인이 차를 그룹에서 뺌그 저장은 받지 않아요. 대던 폰에 "이 차는 이제 그룹에 없어요. 저장하지 못했어요"를 띄우고 홈에서 카드를 내려요. 주인 쪽 자리는 안 바뀌어요.
마지막 그룹에서 나감혼자 쓰는 상태(B-5)로 돌아가요. 내 차·기록·위젯은 그대로, 그룹 알림 2줄과 "보이는 그룹" 묶음은 숨겨요.
그룹 수 한도폰 하나에 3개 추천 (가족·회사·하나 더). 3개가 되면 "＋ 그룹 추가" 줄이 사라져요 — 차 4대 한도와 같은 방식.
같은 사람이 내 두 그룹에 다 있음그 사람에게 내 차 카드는 한 장, 알림도 한 번 (차 기준으로 합쳐요). 멤버 목록엔 그룹마다 따로 나오고 이름은 그룹마다 다를 수 있어요.
차 한 대를 두 그룹이 동시에 고침지금 가족과 같아요 — 나중에 온 기록이 이겨요. 누가 댔는지는 이름으로 보여요.
다른 사람 차가 많아짐홈에서 다른 사람 차는 접을 수 있게 할지 → 아래 결정 5.

결정할 것

  1. 포함 토글 위치 — 추천: 그룹 화면 + 차 화면 양쪽.다른 안: 그룹 화면에만 두고 차 화면엔 그룹 이름만 표시 (차 화면이 짧아짐).
  2. 홈의 그룹 표시 — 추천: 다른 사람 차에만 "○○님 차 · 그룹 이름".다른 안: 모든 카드에 표시 / 아예 없음.
  3. 그룹 수 한도 — 추천 3개.다른 안: 2개(가족+회사만) / 5개.
  4. 그룹마다 내 이름 — 추천: 그룹마다 따로 (가족엔 "아빠", 회사엔 "민수"). 들어갈 때 이미 이름을 묻고 있어요.다른 안: 폰 하나에 이름 하나.
  5. 다른 사람 차 한도 — 회사 그룹에 차가 10대면 홈이 길어져요. 추천: 홈엔 다른 사람 차를 최근 3대만 보이고 "N대 더 보기".다른 안: 전부 보이기 / 그룹당 차 수 한도.
  6. 다른 사람 차 알림 기본값 — 추천: 꺼짐 (내 차는 지금처럼 켜짐).다른 안: 가족처럼 전부 켜짐.
  7. 첫 실행 때 그룹 자동 만들기 — 지금은 "○○네 가족"을 자동으로 만들어요. 추천: 자동으로 만들지 않고 첫 초대를 보낼 때 만들기 (B-5).다른 안: 지금처럼 자동, 이름만 "○○네 그룹".
  8. 기존 사용자 옮기기 — 추천: 지금 가족이 그대로 첫 그룹이 되고, 가족이 같이 보던 차는 등록한 사람의 "내 차"로 그 그룹에 켜진 채 넘어가요.등록한 사람을 모르는 옛 차는 방장 차로 둘지 확인 필요.
