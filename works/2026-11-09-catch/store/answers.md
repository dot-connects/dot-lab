# 리얼뽑기 — Play Console answers (paste sheet)

Drafted 2026-11-18 from `page/privacy.html` and `spec-release.md` §6. The operator pastes these into Play Console
(wizard menu 3, "앱 설정" tasks). If a form asks something not here, capture the screen and send it to Claude.

## 앱 액세스 (App access)
- 모든 기능을 별도 액세스 권한 없이 사용할 수 있음 (로그인 없음).

## 광고 (Ads)
- 아니요, 앱에 광고가 없습니다.

## 콘텐츠 등급 (Content rating, IARC)
- 카테고리: 게임 (위자드 앱 만들기에서 "게임"으로 만든 것과 맞춤). 아래처럼 답한다.
- 폭력, 성적 콘텐츠, 욕설, 약물, 도박: 모두 아니요.
- 사용자 간 소통·콘텐츠 공유: 아니요 (앱 안에 채팅·게시판 없음).
- 사용자 위치 공유: 아니요.
- 디지털 상품 구매: 예 (펫 그림 500원, Google Play 결제).
- AI 생성 콘텐츠: 예 — 사용자가 고른 사진으로 그림을 만든다 (아래 "AI 콘텐츠" 참고).

## 타겟층 (Target audience)
- 만 13–15세, 16–17세, 18세 이상. 13세 미만 제외.
- 아동에게 호소하는 앱인가: 아니요 (스토어 등록정보에 아동 대상 표현 없음).

## 데이터 보안 (Data safety)
- 데이터 수집 또는 공유: 예.
- 전송 중 암호화: 예 (HTTPS).
- 사용자가 데이터 삭제를 요청할 수 있음: 예 (개인정보 처리방침의 메일, 기기 번호로 요청 → 7일 안에 삭제).

| 데이터 유형 | 수집 | 공유 | 처리 방식 | 필수/선택 | 목적 |
|---|---|---|---|---|---|
| 사진 및 동영상 → 사진 | 예 | 예 (OpenAI, 그림 처리) | 일시적 처리 (그린 뒤 버림. 산 펫 그림 결과만 30일) | 선택 (그림을 만들 때만) | 앱 기능 |
| 앱 활동 → 기타 사용자 생성 콘텐츠 (신고 이유) | 예 | 아니요 | 저장 | 선택 | 앱 기능, 사기 방지·보안 |
| 기기 또는 기타 ID (앱이 만든 무작위 기기 번호) | 예 | 아니요 | 저장 | 필수 (그림을 만들 때) | 사기 방지·보안, 앱 기능 |
| 금융 정보 → 구매 내역 (구매 토큰·상품명) | 예 | 아니요 | 저장 | 선택 | 앱 기능 |

- 카메라 영상: 수집 안 함 (폰 안에서만 처리).
- 사용 정보 접근(맨 앞 앱 이름): 수집 안 함 (폰 안에서만, 기록·전송 없음).
- 이름·이메일·위치·연락처: 수집 안 함.

## AI 콘텐츠 (Generative AI declaration)
- 사용자 입력(도감의 사진 한 장)으로 이미지를 생성한다.
- 막는 장치: 사람이 찍힌 사진은 보내기 전에 "사진 속 사람에게 물어봤나요?"를 확인, 그림마다 "신고" 버튼
  (이상하거나 불쾌해요 / 사람이 잘못 그려졌어요 / 기타), 생성 모델 제공자(OpenAI)의 콘텐츠 정책 필터.

## 포그라운드 서비스 (FOREGROUND_SERVICE_SPECIAL_USE)
- 유형: specialUse.
- 설명 (붙여 넣기):
  "사용자가 '펫 띄우기'를 켜면, 사용자가 뽑은 털뭉치 펫이 홈 화면 위를 걸어 다니는 오버레이를 그립니다. 펫은
  사용자가 끌 때까지(앱 안 스위치, 알림, 펫 말풍선의 '펫 끄기') 계속 보여야 하므로 포그라운드 서비스로 실행하며,
  실행 중에는 알림이 항상 표시됩니다. 다른 포그라운드 서비스 유형(미디어 재생, 위치 등)에 해당하지 않습니다."
- 영상: 30초 안팎, 화면 녹화 — 앱에서 펫 고르기 → '펫 띄우기' 켜기 → 홈 화면에서 걷는 펫 → 알림 표시 →
  펫 두 번 톡 → '펫 끄기'로 종료. (촬영 목록: 아래 listing.md "찍을 화면")

## 민감한 권한
- `SYSTEM_ALERT_WINDOW`: 홈 화면 위에 펫을 그리기 위해. 사용자가 '다른 앱 위에 표시'를 직접 허용.
- `PACKAGE_USAGE_STATS` (선택): "홈 화면에서만 펫 보이기"와 두 번 톡의 "최근 앱 / 자주 쓴 앱" 목록을 위해,
  맨 앞 앱과 최근 사용 앱 이름을 폰 안에서만 읽음. 기록·전송 없음. 허용하지 않아도 앱의 나머지는 동작.
