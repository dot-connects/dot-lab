## 한 줄
서울의 땅은 지금 **시속 1,327km** 로 돈다. 그 땅을 멈추면 — 당신과 공기는 어떻게 될까?

## 핵심 재미
- 금지된 버튼을 직접 누르는 느낌 (neal.fun Trolley: 레버 하나 → 8초 안에 결과)
- **멈추는 데 걸리는 시간**만 바꿨는데 땅·당신·공기 세 숫자가 서로 다르게 움직이는 반전
- 다시 할 이유 = **비교 사다리**: 슬라이더를 움직이면 지금 받는 가속도가 전투기·롤러코스터·급정거·지하철과 실시간으로 비교된다. "지하철 급정거보다 약하려면 최소 몇 분?"을 직접 찾는 과제

## 사용자 행동 (설명 문구 없이)
1. 첫 화면: 도는 지구 + 서울 점 + 질문 "지구가 멈추면?" + 큰 버튼 [멈추기]. **첫 멈추기는 1초 고정**
2. 탭 → 세 숫자 중 「땅」만 1,327 → 0 으로 떨어지고 「당신」「공기」는 1,327 그대로 → 사물이 동쪽으로 날아감
3. 결과 카드 → "천천히 멈춰 볼까?" 로그 슬라이더(1초 ~ 1년) 등장, 다섯 결말 눈금(1초·1분·1시간·1일·1년)
4. 슬라이더를 움직이며 다시 멈추기 → 결말 카드 수집(●●○○○) + 비교 사다리에서 내 위치

## 화면 구성 (폰 세로, 한 화면)
```
┌──────────────────────────┐
│ 땅    1,327 → 0 km/h      │  ← 숫자 셋 (Deep Sea 고정 숫자 문법을 셋으로)
│ 당신  1,327 km/h           │     1초: 땅만 0 / 1시간: 땅·당신 0, 공기만 남음
│ 공기  1,327 km/h           │
│ 시뮬레이션 · 단순 모델 ⓘ    │  ← 가정 칩
│        ( 지구 )            │
│          · 서울            │
│ 37.6 g  ▲전투기 9 g        │  ← 비교 사다리 (첫 결과 뒤)
│ 1초 ━━●━━━━━━━━ 1년        │  ← 로그 슬라이더 + 결말 눈금 5개
│       [ 멈추기 ]           │  ← 엄지 닿는 하단
└──────────────────────────┘
```
조작은 하단 1/3 에만 둔다(Sandspiel 처럼 상단을 버튼으로 채우지 않는다).

## 물리 모델과 가정 (칩에 그대로 표시)
- **자전만 멈춘다.** 공전은 그대로. 땅(지각)이 주어진 시간 동안 고르게 감속한다
- 땅에 붙어 있는 사람·건물은 땅과 같이 감속한다. 붙어 있지 않은 물건은 관성으로 원래 속도를 유지한다
- 공기와 바다는 땅과의 마찰로 며칠에 걸쳐 느려진다. 이 시제품은 그 감속을 계산하지 않고 **상한값(원래 속도 유지)** 으로 보여 준다. 칩에 "1시간·1일 칸 바람은 상한값"이라고 적는다
- 서울 위도 37.57°: 적도 속도 465.1 m/s × cos 37.57° = **368.7 m/s = 1,327 km/h** (지구 둘레 40,075 km ÷ 항성일 86,164 s)
- 땅에 붙어 있으면 받는 가속도 = 368.7 m/s ÷ 멈추는 시간 (힘이 아니라 가속도, g 로 표시)

| 결말 눈금 | 가속도 | 결말 카드 |
|---|---|---|
| 1초 | **37.6 g** | 땅이 발밑에서 시속 1,327km 로 빠져나간다. 땅에 붙지 않은 모든 것이 동쪽으로 날아간다 |
| 1분 | 0.63 g | 1분 내내 약 32° 비탈에 선 것처럼 밀린다. 서 있기 힘들고, 안 붙잡힌 물건은 미끄러진다 |
| 1시간 | 0.01 g | 몸은 거의 못 느낀다. 그런데 공기는 남는다 — 최대 시속 1,327km, **음속(약 1,225km/h)보다 빠른 바람** |
| 1일 | 0.0004 g | 몸은 못 느낀다. 바람은 상한값으로는 1시간 칸과 같고, 실제로는 마찰로 상당 부분 줄어든다 |
| 1년 | ≈ 0 | 몸도 바람도 버틴다 |

**모든 카드 끝에 같은 한 줄:** "그리고 그다음엔 — 하루가 1년이 된다(낮 반년·밤 반년), 바다는 극지방으로 몰리고 적도에 큰 대륙이 드러난다."
(멈춘 시간과 무관한 자전 0 의 최종 상태이므로 1년 칸에만 붙이지 않는다.)

**판정 문구:** "1년이면 몸은 버틴다. 세상은 못 버틴다." — '산다'고 쓰지 않는다(극한 온도, 바닷물 재배치).

**비교 사다리** (같은 368.7 m/s 를 멈추는 시간, 계산값):
| 비교 | 대략 g | 이보다 약하려면 최소 |
|---|---|---|
| 전투기 조종사 한계 | 9 g | 4.2초 |
| 롤러코스터 | 4.5 g | 8.4초 |
| 자동차 급정거 | 0.8 g | 47초 |
| 지하철 급정거 | 0.15 g | 4분 11초 |
비교 g 값(전투기·롤러코스터·자동차·지하철)은 출처를 붙이고 '대략'으로 표시한다.

출처 URL 필요(시제품 전, `whatif_facts` 표 형식): 음속 15℃ 340 m/s, 바다 이동(ESRI, Fraczek 2008), 비교 g 4종.

## 구현 범위
- 단일 HTML + Canvas 2D, 라이브러리 없음. 지구는 원 + 대륙 실루엣(공개 도메인 지도 단순화, 수십 KB) + 서울 점
- 연출: 멈추는 순간 흔들림·사물(나무·차·사람 실루엣) 동쪽으로 날아감 / 바람 선 / 마지막 줄의 바다가 극으로 흐르는 2초 애니메이션
- 효과음: 탭 이후에만. 소리 없이도 재미가 서야 한다
- 공유 카드: "실험 #1 지구 멈추기 · 5가지 결말 중 3 · 지하철보다 약하려면 4분 11초" 한 장. `navigator.share({files})` 를 먼저 쓰고, 안 되면 이미지를 띄워 길게 눌러 저장 안내 — **인스타 인앱 브라우저에서 실측**
- **빼는 것:** 도시 고르기(2판 후보), 공기·바다 감속 계산, 3D, 계정·로그인, 점수 서버

- 실측: 헤드리스 Chrome 430px + CDP 터치, 인스타 인앱 브라우저, 운영자 폰(Fold)
